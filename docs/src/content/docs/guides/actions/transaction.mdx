TCSwap provides a unified interface for creating and executing transactions across multiple blockchain networks. This guide explains how to perform transactions with the TCSwap library.

## Two Approaches for Using TCSwap

You can use TCSwap in two ways:

1. **Granular approach** - Import only what you need from individual packages (recommended for frontend):

   ```ts
   import { USwap, evmWallet } from "@tcswap/sdk";
   ```

2. **All-in-one approach** - Import everything from the SDK (better for backend/Node.js):
   ```ts
   import { createUSwap } from "@tcswap/sdk";
   ```

## Basic Asset Transfer

The most common transaction is transferring assets from one address to another.

### Granular Approach (Frontend Recommended)

```ts twoslash
import {
  AssetValue,
  Chain,
  FeeOption,
  USwap,
  getExplorerTxUrl,
  keystoreWallet,
} from "@tcswap/sdk";

const uSwap = USwap({
  wallets: { ...keystoreWallet },
});

await uSwap.connectKeystore([Chain.Ethereum], "your secret phrase here");

const amount = AssetValue.from({ chain: Chain.Ethereum, value: "0.01" });

async function transferAsset() {
  try {
    const txHash = await uSwap.transfer({
      assetValue: amount,
      recipient: "0x742d35Cc6634C0532925a3b844Bc454e4438f44e",
      memo: "Payment for services",
      feeOptionKey: FeeOption.Fast,
    });

    const txUrl = getExplorerTxUrl({
      chain: Chain.Ethereum,
      txHash,
    });

    return { txHash, txUrl };
  } catch (error) {
    throw error;
  }
}
```

### All-in-one Approach (Backend)

```ts twoslash
import { AssetValue, Chain, FeeOption, createUSwap } from "@tcswap/sdk";

const uSwap = createUSwap();

await uSwap.connectKeystore([Chain.Ethereum], "your secret phrase here");

const amount = AssetValue.from({ chain: Chain.Ethereum, value: "0.01" });

async function transferAsset() {
  try {
    const txHash = await uSwap.transfer({
      assetValue: amount,
      recipient: "0x742d35Cc6634C0532925a3b844Bc454e4438f44e",
      feeOptionKey: FeeOption.Fast,
    });

    return txHash;
  } catch (error) {
    throw error;
  }
}
```

## Transferring Different Asset Types

### Transferring ERC20 Tokens

```ts twoslash
import { AssetValue, Chain, FeeOption, USwap, evmWallet } from "@tcswap/sdk";

const uSwap = USwap({
  wallets: { ...evmWallet },
});

await uSwap.connectEVMWallet([Chain.Ethereum]);

async function transferERC20() {
  const usdcAmount = await AssetValue.from({
    asset: "ETH.USDC-0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48",
    value: "10",
    asyncTokenLookup: true,
  });

  const txHash = await uSwap.transfer({
    assetValue: usdcAmount,
    recipient: "0x742d35Cc6634C0532925a3b844Bc454e4438f44e",
    feeOptionKey: FeeOption.Average,
  });

  return txHash;
}
```

## Using Toolboxes Directly for Transactions

For lower-level control, you can use the toolboxes directly instead of TCSwap's high-level API:

### EVM Toolbox Transfers

```ts twoslash
import { AssetValue, Chain, FeeOption, getEvmToolbox } from "@tcswap/sdk";

async function directEVMTransfer() {
  const ethToolbox = await getEvmToolbox(Chain.Ethereum, {
    phrase: "your twelve word mnemonic phrase here",
  });

  const amount = AssetValue.from({ chain: Chain.Ethereum, value: "0.01" });

  const txHash = await ethToolbox.transfer({
    assetValue: amount,
    recipient: "0x742d35Cc6634C0532925a3b844Bc454e4438f44e",
    feeOptionKey: FeeOption.Fast,
  });

  return txHash;
}
```

### UTXO Toolbox Transfers

```ts twoslash
import { AssetValue, Chain, FeeOption, getUtxoToolbox } from "@tcswap/sdk";

async function directBitcoinTransfer() {
  // The toolbox derives a signer from the phrase and signs inside transfer()
  const btcToolbox = await getUtxoToolbox(Chain.Bitcoin, {
    phrase: "your twelve word mnemonic phrase here",
  });

  const amount = AssetValue.from({ chain: Chain.Bitcoin, value: "0.001" });

  const txHash = await btcToolbox.transfer({
    assetValue: amount,
    recipient: "bc1qar0srrr7xfkvy5l643lydnw9re59gtzzwf5mdq",
    feeOptionKey: FeeOption.Fast,
  });

  return txHash;
}
```

## Working with Contract Interactions

For EVM chains, you can interact with smart contracts using the EVM toolbox:

```ts twoslash
import { Chain, getEvmToolbox } from "@tcswap/sdk";
import { erc20ABI } from "@tcswap/helpers/contracts";
import { formatUnits } from "ethers";

async function interactWithContract() {
  const ethToolbox = await getEvmToolbox(Chain.Ethereum, {
    phrase: "your twelve word mnemonic phrase here",
  });

  const address = await ethToolbox.getAddress();

  const contractAddress = "0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48";

  const tokenName = await ethToolbox.call({
    contractAddress,
    abi: erc20ABI,
    funcName: "name",
  });

  const tokenSymbol = await ethToolbox.call({
    contractAddress,
    abi: erc20ABI,
    funcName: "symbol",
  });

  const tokenDecimals = await ethToolbox.call<number>({
    contractAddress,
    abi: erc20ABI,
    funcName: "decimals",
  });

  const balance = await ethToolbox.call<string>({
    contractAddress,
    abi: erc20ABI,
    funcName: "balanceOf",
    funcParams: [address],
  });

  const formattedBalance = formatUnits(balance, tokenDecimals);

  return {
    name: tokenName,
    symbol: tokenSymbol,
    decimals: tokenDecimals,
    balance: formattedBalance,
  };
}
```
