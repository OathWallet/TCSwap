TCSwap provides ways to sign transactions and messages across different blockchains. This guide shows how to use these signing capabilities with both granular and all-in-one package approaches.

## Two Approaches for Using TCSwap

You can use TCSwap in two ways:

1. **Granular approach** - Import only what you need from individual packages (recommended for frontend):

   ```ts
   import { USwap, evmWallet } from "@tcswap/sdk";
   ```

2. **All-in-one approach** - Import everything from the SDK (better for backend/Node.js):
   ```ts
   import { createUSwap } from "@tcswap/sdk";
   ```

## Signing Messages

Signing messages is useful for authentication, proving ownership of an address, or interacting with decentralized applications.

### Granular Approach

```ts twoslash
import { Chain, USwap, evmWallet } from "@tcswap/sdk";

const uSwap = USwap({
  wallets: { ...evmWallet },
});

async function signMessageExample() {
  await uSwap.connectEVMWallet([Chain.Ethereum]);

  const message = "I am proving ownership of this wallet address";

  try {
    const signature = await uSwap.signMessage({
      chain: Chain.Ethereum,
      message,
    });

    return signature;
  } catch (error) {
    throw error;
  }
}
```

### All-in-one Approach

```ts twoslash
import { Chain, createUSwap } from "@tcswap/sdk";

const uSwap = createUSwap();

async function signMessageExample() {
  await uSwap.connectKeystore([Chain.Ethereum], "your secret phrase here");

  const message = "I am proving ownership of this wallet address";

  try {
    const signature = await uSwap.signMessage({
      chain: Chain.Ethereum,
      message,
    });

    return signature;
  } catch (error) {
    throw error;
  }
}
```

## Signing with Different Chains

Different blockchains have different message signing formats. Message signing depends on the connected wallet: for example, the keystore wallet only supports `signMessage` on EVM chains, while Ledger also supports THORChain. If the connected wallet can't sign messages for a chain, `signMessage` throws a `USwapError` with the `core_wallet_sign_message_not_supported` key.

```ts twoslash
import { Chain, USwap, evmWallet, ledgerWallet } from "@tcswap/sdk";

const uSwap = USwap({
  wallets: { ...evmWallet, ...ledgerWallet },
});

async function setupWallets() {
  await uSwap.connectLedger([Chain.THORChain]);

  await uSwap.connectEVMWallet([Chain.Ethereum]);
}

async function signCosmosMessage() {
  const message = "Sign this message to verify your THORChain address";

  try {
    const signature = await uSwap.signMessage({
      chain: Chain.THORChain,
      message,
    });

    return signature;
  } catch (error) {
    throw error;
  }
}
```

## Verifying Signed Messages

After signing a message, you or others may want to verify the signature:

```ts twoslash
import { Chain, USwap, keystoreWallet } from "@tcswap/sdk";

const uSwap = USwap({
  wallets: { ...keystoreWallet },
});

async function verifySignature() {
  const message = "I am proving ownership of this wallet address";

  const address = "thor1fkm5w5uum0j5h9g35vwqtf7angh9uvrm9mszyx";

  const signature =
    "ac7bfd5b5c9f44788fb533b7f08b213a3e3856e75ecdb19c5e9138ba29c4c1681e82b7de139e0b92cd9442297ec7fdd2c14e7034a3aa417ff9756e9b591d93201";

  try {
    const isValid = await uSwap.verifyMessage({
      chain: Chain.THORChain,
      message,
      address,
      signature,
    });

    return isValid;
  } catch (error) {
    return false;
  }
}
```

## Signing Transactions

In most cases, TCSwap handles transaction signing internally when using methods like `transfer` or `swap`. However, there are cases where you might want to create and sign a transaction separately.

### Using Toolboxes for Transaction Signing

For more control over the signing process, you can use toolboxes directly:

```ts twoslash
import { Chain, getEvmToolbox } from "@tcswap/sdk";
import { parseEther } from "ethers";

async function signEthereumTransaction() {
  const ethToolbox = await getEvmToolbox(Chain.Ethereum, {
    phrase: "your twelve word mnemonic phrase here",
  });

  const from = await ethToolbox.getAddress();

  const transaction = {
    to: "0x742d35Cc6634C0532925a3b844Bc454e4438f44e",
    value: parseEther("0.01"),
    data: "0x",
    from,
  };

  try {
    // Signs and broadcasts the transaction, returning the tx hash
    const txHash = await ethToolbox.sendTransaction(transaction);

    return txHash;
  } catch (error) {
    throw error;
  }
}
```

### Bitcoin Transaction Signing

For UTXO chains like Bitcoin, the process involves creating inputs and outputs:

```ts twoslash
import { AssetValue, Chain, getUtxoToolbox } from "@tcswap/sdk";

async function signBitcoinTransaction() {
  const btcToolbox = await getUtxoToolbox(Chain.Bitcoin);

  const keys = btcToolbox.createKeysForPath({
    phrase: "your twelve word mnemonic phrase here",
    derivationPath: "m/84'/0'/0'/0/0",
  });

  const fromAddress = btcToolbox.getAddressFromKeys(keys);

  const amount = AssetValue.from({ chain: Chain.Bitcoin, value: "0.001" });

  const recipient = "bc1qar0srrr7xfkvy5l643lydnw9re59gtzzwf5mdq";

  try {
    const { psbt } = await btcToolbox.createTransaction({
      sender: fromAddress,
      recipient,
      assetValue: amount,
      feeRate: 2,
      memo: "Test transaction",
    });

    psbt.signAllInputs(keys);
    psbt.finalizeAllInputs();

    const txHash = await btcToolbox.broadcastTx(psbt.extractTransaction().toHex());

    return txHash;
  } catch (error) {
    throw error;
  }
}
```

## Custom Transaction Signing with Hardware Wallets

Hardware wallets like Ledger or Trezor have special requirements for signing:

```ts twoslash
import {
  AssetValue,
  Chain,
  FeeOption,
  USwap,
  WalletOption,
  ledgerWallet,
} from "@tcswap/sdk";

const uSwap = USwap({
  wallets: { ...ledgerWallet },
});

async function signWithLedger() {
  try {
    await uSwap.connectLedger([Chain.Ethereum]);

    const wallet = uSwap.getWallet(WalletOption.LEDGER, Chain.Ethereum);

    const txHash = await wallet.transfer({
      assetValue: AssetValue.from({ chain: Chain.Ethereum, value: "0.01" }),
      feeOptionKey: FeeOption.Fast,
      sender: wallet.address,
      memo: "Ledger transfer",
      recipient: "0x742d35Cc6634C0532925a3b844Bc454e4438f44e",
    });

    return txHash;
  } catch (error) {
    throw error;
  }
}
```

## Using Low-level Toolbox Signing Methods

For complete control over the signing process, you can use toolbox-specific methods:

```ts twoslash
import { Chain, NetworkDerivationPath, getCosmosToolbox } from "@tcswap/sdk";

async function cosmosWallet() {
  const phrase = "your twelve word mnemonic phrase here";
  const cosmosToolbox = await getCosmosToolbox(Chain.THORChain, { phrase });

  const signer = await cosmosToolbox.getSignerFromPhrase({
    phrase,
    derivationPath: NetworkDerivationPath[Chain.THORChain],
  });
  const address = await cosmosToolbox.getAddress();

  return { signer, address };
}
```
