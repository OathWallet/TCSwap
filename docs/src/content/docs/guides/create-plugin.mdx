TCSwap plugins extend the functionality of the core library to support various DeFi protocols and services. This guide explains how to create a custom plugin for TCSwap.

## Plugin Structure

A TCSwap plugin consists of the following components:

1. A plugin factory created with `createPlugin`
2. Plugin methods that interact with external services or smart contracts
3. Integration with the TCSwap client

## Basic Plugin Example

Here's a simple example of creating a plugin:

```ts twoslash
import {
  AssetValue,
  USwapError,
  createPlugin,
  type EVMChain,
} from "@tcswap/sdk";

type ExampleRoute = {
  sellAsset: string;
  buyAsset: string;
  sellAmount: string;
  targetAddress: string;
};

export const ExamplePlugin = createPlugin({
  name: "example",
  methods: ({ getWallet }) => ({
    swap: async function exampleSwap({ route }: { route: ExampleRoute }) {
      const { sellAsset, buyAsset, sellAmount, targetAddress } = route;

      if (!(sellAsset && buyAsset)) {
        throw new USwapError("core_swap_asset_not_recognized");
      }

      const assetValue = await AssetValue.from({
        asyncTokenLookup: true,
        asset: sellAsset,
        value: sellAmount,
      });

      const wallet = getWallet(assetValue.chain as EVMChain);

      if (!wallet) {
        throw new USwapError("core_wallet_connection_not_found");
      }

      return wallet.transfer({ assetValue, recipient: targetAddress });
    },

    getQuote: async function getExampleQuote({
      sellAsset,
      buyAsset,
      sellAmount,
    }: Omit<ExampleRoute, "targetAddress">) {
      // Call your service here and map its response
      return {
        sellAsset,
        buyAsset,
        sellAmount,
        targetAddress: "0x742d35Cc6634C0532925a3b844Bc454e4438f44e",
      } satisfies ExampleRoute;
    },
  }),
});
```

`createPlugin` returns an object keyed by the plugin `name` (here `{ example: ... }`). The optional `properties.supportedUSwapProviders` field takes existing `ProviderName` values; `uSwap.swap({ route })` uses it to pick the plugin that matches `route.providers[0]` when no `pluginName` is passed.

## Creating an EVM-based Swap Plugin

Here's a more realistic example of an EVM-based plugin that integrates with an exchange:

```ts twoslash
import {
  ApproveMode,
  AssetValue,
  EVMChains,
  USwapError,
  createPlugin,
  type EVMChain,
  type EVMTransaction,
  type SwapKitPluginParams,
} from "@tcswap/sdk";

const ROUTER_ADDRESS = "0x1234567890123456789012345678901234567890";

// uSwap.approveAssetValue(assetValue, "exchange") and
// uSwap.isAssetValueApproved(assetValue, "exchange") call these with { assetValue }
const approve = <T extends ApproveMode>({
  approveMode,
  getWallet,
}: { approveMode: T } & SwapKitPluginParams) =>
  async function ({ assetValue }: { assetValue: AssetValue }) {
    const evmChain = assetValue.chain as EVMChain;

    if (!EVMChains.includes(evmChain) || assetValue.isGasAsset) {
      return approveMode === ApproveMode.CheckOnly ? true : "approved";
    }

    const wallet = getWallet(evmChain);

    if (!(wallet && assetValue.address)) {
      throw new USwapError("core_wallet_connection_not_found");
    }

    const params = {
      amount: assetValue.getBaseValue("bigint"),
      assetAddress: assetValue.address,
      from: wallet.address,
      spenderAddress: ROUTER_ADDRESS,
    };

    return approveMode === ApproveMode.CheckOnly
      ? wallet.isApproved(params)
      : wallet.approve(params);
  };

type ExchangeRoute = {
  sellAsset: string;
  buyAsset: string;
  sellAmount: string;
  expectedBuyAmount: string;
  tx: EVMTransaction;
};

export const ExchangePlugin = createPlugin({
  name: "exchange",
  methods: ({ getWallet }) => ({
    approveAssetValue: approve({ approveMode: ApproveMode.Approve, getWallet }),
    isAssetValueApproved: approve({ approveMode: ApproveMode.CheckOnly, getWallet }),

    swap: async function exchangeSwap({ route }: { route: ExchangeRoute }) {
      const { tx, sellAsset } = route;

      if (!tx) {
        throw new USwapError("core_swap_invalid_params");
      }

      const assetValue = await AssetValue.from({
        asset: sellAsset,
        asyncTokenLookup: true,
      });

      const evmChain = assetValue.chain as EVMChain;
      const wallet = getWallet(evmChain);

      if (!wallet) {
        throw new USwapError("core_wallet_connection_not_found");
      }

      const { from, to, data, value } = tx;
      return wallet.sendTransaction({
        from,
        to,
        data,
        value: BigInt(value || 0),
      });
    },

    getQuote: async function getExchangeQuote({
      sellAsset,
      buyAsset,
      sellAmount,
      slippage = 1,
    }: {
      sellAsset: string;
      buyAsset: string;
      sellAmount: string;
      slippage?: number;
    }): Promise<ExchangeRoute> {
      const response = await fetch("https://api.example-exchange.com/quote", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ sellAsset, buyAsset, sellAmount, slippage }),
      });

      if (!response.ok) {
        throw new Error(`API error: ${response.status}`);
      }

      const quoteData = await response.json();

      return {
        sellAsset,
        buyAsset,
        sellAmount,
        expectedBuyAmount: quoteData.buyAmount,
        tx: {
          from: quoteData.from,
          to: quoteData.to,
          data: quoteData.data,
          value: quoteData.value,
        },
      };
    },
  }),
});
```

## Using Your Plugin with TCSwap

Once you've created your plugin, spread it into `plugins` and access it on the client by its `name`:

```ts twoslash
import { createUSwap, Chain } from "@tcswap/sdk";

import { ExchangePlugin } from "./exchange-plugin";

// createUSwap merges your plugins/wallets with the default ones (incl. keystore)
const uSwap = createUSwap({
  plugins: { ...ExchangePlugin },
});

async function connectAndUsePlugin() {
  await uSwap.connectKeystore([Chain.Ethereum], "your secret phrase here");

  const route = await uSwap.exchange.getQuote({
    sellAsset: "ETH.ETH",
    buyAsset: "ETH.USDC-0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48",
    sellAmount: "0.1",
  });

  // Call the plugin directly...
  const txHash = await uSwap.exchange.swap({ route });

  // ...or route through uSwap.swap by plugin name
  // await uSwap.swap({ route, pluginName: "exchange" });
}
```

## Best Practices

When creating a TCSwap plugin, follow these best practices:

1. **Error Handling**: Use USwapError for consistent error reporting
2. **Type Safety**: Leverage TypeScript to provide proper type definitions
3. **Documentation**: Document your plugin methods and parameters
4. **Testing**: Create comprehensive tests for all functionality
5. **Validation**: Validate inputs to prevent runtime errors
6. **Security**: Be careful with sensitive data and external API calls

By following this guide, you should be able to create, test, and integrate custom plugins with TCSwap.
