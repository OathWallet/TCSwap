The `USwapApi` provides access to swap quotes, price feeds, token lists, and other essential data. All methods are available through the `@tcswap/helpers/api` import.

## Getting Started

```typescript
// @noErrorValidation
import { USwapApi } from "@tcswap/helpers/api";

const [ethPrice] = await USwapApi.getPrice({
  tokens: [{ identifier: "ETH.ETH" }],
  metadata: false,
});

console.log(ethPrice?.price_usd);
```

## Swap Quotes

### getSwapQuote

Get swap quotes from multiple providers. Amounts are human-readable decimal strings (e.g. `"1"` = 1 ETH):

```typescript
// @noErrorValidation
const { routes, providerErrors } = await USwapApi.getSwapQuote({
  sellAsset: 'ETH.ETH',
  sellAmount: '1',
  buyAsset: 'BTC.BTC',
  sourceAddress: '0x...',
  destinationAddress: 'bc1q...',
  slippage: 3,
  providers: ['THORCHAIN', 'CHAINFLIP', 'UNISWAP_V3'],
  affiliate: 'your-affiliate-id',
  affiliateFee: 100,
  refundAddress: '0x...',
});

// Response shape (QuoteResponse)
{
  routes: [{
    providers: ['THORCHAIN'],
    sellAsset: 'ETH.ETH',
    sellAmount: '1',
    buyAsset: 'BTC.BTC',
    expectedBuyAmount: '0.0625',
    expectedBuyAmountMaxSlippage: '0.060625',
    sourceAddress: '0x...',
    destinationAddress: 'bc1q...',
    targetAddress: '0x...',
    inboundAddress: '0x...',
    memo: '=:BTC.BTC:bc1q...',
    expiration: '1704067800',
    fees: [
      { type: 'inbound', amount: '0.0005', asset: 'ETH.ETH', chain: 'ETH', protocol: 'THORCHAIN' },
      { type: 'liquidity', amount: '0.0003', asset: 'ETH.ETH', chain: 'ETH', protocol: 'THORCHAIN' },
      { type: 'affiliate', amount: '0.001', asset: 'ETH.ETH', chain: 'ETH', protocol: 'THORCHAIN' },
    ],
    estimatedTime: {
      inbound: 600,

        buyAsset: 'BTC.BTC',
        sellAmount: '1',
        buyAmount: '0.0625',
        buyAmountMaxSlippage: '0.060625'
      }

  providerErrors: [],

}
```

## Rate Limits

The TCSwap API has rate limits that vary by endpoint:

- **Without API key**: 10 requests per minute
- **With API key**: 100 requests per minute

Configure your API key in [Configuration](/start/configuration):

```typescript
// @noErrorValidation
import { createUSwap } from "@tcswap/sdk";

const uSwap = createUSwap({
  config: {
    apiKeys: {
      uSwap: "your-api-key",
    },
  },
});
```

## Error Handling

All API methods can throw errors that should be handled:

```typescript
// @noErrorValidation
import { USwapError } from '@tcswap/sdk';

try {
  const quote = await USwapApi.getSwapQuote({...});
} catch (error) {
  if (error instanceof USwapError) {
    // The error key is the message (e.g. "api_v2_server_error"), the source error is in `cause`
    console.error('API Error:', error.message, error.cause);

    if (error.message.startsWith('api_v2_server_error')) {
      // The API returned an error for this quote request
    } else if (error.message.startsWith('api_v2_invalid_response')) {
      // The API response did not match the expected schema
    }
  }
}
```

## Common Patterns

### Best Route Selection

When getting swap quotes, the first route is typically the best:

```typescript
// @noErrorValidation
import { AssetValue } from '@tcswap/sdk';

const { routes } = await USwapApi.getSwapQuote({...});

if (routes.length > 0) {
  const bestRoute = routes[0];


  // Quote amounts are decimal strings, not base units
  const minOutput = AssetValue.from({
    asset: bestRoute.buyAsset,
    value: bestRoute.expectedBuyAmountMaxSlippage ?? bestRoute.expectedBuyAmount,
  });

  if (minOutput.gte(requiredAmount)) {
    await uSwap.swap({ route: bestRoute });
  }
}
```

### Price Impact Calculation

Calculate price impact for large swaps:

```typescript
// @noErrorValidation
const quote = await USwapApi.getSwapQuote({...});
const route = quote.routes[0];

// Price impact reported by the API (if provided)
console.log("Reported price impact:", route.meta?.priceImpact);

// Or compute it from USD prices
const [sellPrice, buyPrice] = await USwapApi.getPrice({
  tokens: [{ identifier: route.sellAsset }, { identifier: route.buyAsset }],
  metadata: false,
});

const sellValue = Number(route.sellAmount) * (sellPrice?.price_usd ?? 0);
const buyValue = Number(route.expectedBuyAmount) * (buyPrice?.price_usd ?? 0);

const priceImpact = ((sellValue - buyValue) / sellValue) * 100;
console.log(`Price impact: ${priceImpact.toFixed(2)}%`);
```

### Token Validation

Validate tokens before swapping:

```typescript
// @noErrorValidation
import { ProviderName } from '@tcswap/sdk';

async function validateToken(identifier: string, provider: ProviderName) {
  try {
    const { tokens } = await USwapApi.getTokenList(provider);
    const token = tokens.find((t) => t.identifier.toUpperCase() === identifier.toUpperCase());

    if (!token) return { valid: false };

    return {
      valid: true,
      decimals: token.decimals,
      name: token.name,
      logo: token.logoURI,
    };
  } catch {
    return { valid: false };
  }
}
```

## Configuration Management

### USwapConfig API

The `USwapConfig` API provides methods to manage TCSwap's configuration at runtime. This includes RPC URLs, API keys, custom API endpoints, request options, integrations, and environment settings:

### Core Methods

```typescript
// @noErrorValidation
import { USwapConfig } from '@tcswap/sdk';


const rpcUrls = USwapConfig.get('rpcUrls');
const apiKeys = USwapConfig.get('apiKeys');
const envs = USwapConfig.get('envs');
const integrations = USwapConfig.get('integrations');

const fullState = USwapConfig.getState();

// Merges the given values into the current config
USwapConfig.set({
  apiKeys: { uSwap: 'new-key' },
  envs: { isDev: false },
});

// Request retry/timeout settings used by the internal request client
USwapConfig.setRequestOptions({
  retry: { maxRetries: 3, baseDelay: 300 },
  timeoutMs: 30000,
});

// Reset everything back to defaults
USwapConfig.reinitialize();
```

### API Keys

```typescript
// @noErrorValidation

USwapConfig.setApiKey("uSwap", "your-uswap-key");
USwapConfig.setApiKey("blockchair", "your-blockchair-key");
USwapConfig.setApiKey("walletConnectProjectId", "your-wc-id");
```

### RPC URLs

`setRpcUrl(chain, urls)` takes an array of RPC URLs for the chain (`rpcUrls` in `USwapConfig.set` is also `string[]` per chain):

```typescript
// @noErrorValidation
import { Chain } from '@tcswap/sdk';


USwapConfig.setRpcUrl(Chain.Ethereum, ['https://ethereum-rpc.publicnode.com']);
USwapConfig.setRpcUrl(Chain.Avalanche, ['https://api.avax.network/ext/bc/C/rpc']);
```

### Custom API Endpoints

Override how quotes, routes and balances are fetched (e.g. to proxy through your backend):

```typescript
// @noErrorValidation

USwapConfig.setEndpoint("getQuote", async (quoteRequest) => {
  return myBackend.getQuote(quoteRequest);
});

USwapConfig.setEndpoint("getBalance", async ({ chain, address }) => {
  return myBackend.getBalance(chain, address);
});
```

### Fee Multiplier System

TCSwap provides a unified fee multiplier system across all chains:

```typescript
// @noErrorValidation
import { AssetValue, Chain, FeeOption, getFeeMultiplier, USwapConfig } from "@tcswap/sdk";

// Defaults: Average = 1.0, Fast = 1.5, Fastest = 2.0
const avgMultiplier = getFeeMultiplier(FeeOption.Average);
const fastMultiplier = getFeeMultiplier(FeeOption.Fast);
const fastestMultiplier = getFeeMultiplier(FeeOption.Fastest);

// Override the multipliers globally
USwapConfig.setFeeMultipliers({
  [FeeOption.Average]: 1.0,
  [FeeOption.Fast]: 1.3,
  [FeeOption.Fastest]: 1.8,
});

const baseFee = 1000000;
const fastFee = Math.floor(baseFee * getFeeMultiplier(FeeOption.Fast));

await uSwap.transfer({
  recipient: "0x...",
  assetValue: AssetValue.from({ chain: Chain.Ethereum, value: "1" }),
  feeOptionKey: FeeOption.Fast,
});
```

### Key Features

- **Automatic Stagenet Support**: When `isStagenet` is true, appropriate stagenet URLs are used automatically
- **Custom Endpoints**: Route quote, swap and balance requests through your own backend
- **Runtime Updates**: All configuration can be updated dynamically without recreating TCSwap instances
- **Environment-Based Config**: Easily switch between development, staging, and production environments
- **Unified Fee System**: Consistent fee multipliers across all supported chains

## TypeScript Type Definitions

All TCSwap API methods are fully typed. The request/response types (inferred from the API's zod schemas) are exported from `@tcswap/helpers/api`:

```typescript
// @noErrorValidation
import type {
  QuoteRequest,
  QuoteResponse,
  QuoteResponseRoute,
  QuoteResponseRouteLeg,
  Fees,
  EstimatedTime,
  PriceRequest,
  PriceResponse,
  TrackingRequest,
  TrackerResponse,
  TransactionLegDTO,
  TokensResponseV2,
  TokenListProvidersResponse,
  BrokerDepositChannelParams,
  DepositChannelResponse,
  NearDepositChannelParams,
  NearSwapResponse,
} from "@tcswap/helpers/api";
import type { ChainId, ProviderName } from "@tcswap/sdk";

// Simplified view of the main shapes:

type QuoteRequestShape = {
  sellAsset: string;
  sellAmount: string; // decimal amount, e.g. "1.5"
  buyAsset: string;
  sourceAddress?: string;
  destinationAddress?: string;
  refundAddress?: string;
  slippage?: number; // percent, default 3
  providers?: string[]; // ProviderName keys, e.g. "THORCHAIN"
  affiliate?: string;
  affiliateFee?: number; // basis points
  referrer?: string;
  cfBoost?: boolean;
  dry?: boolean;
  allowSmartContractSender?: boolean;
  allowSmartContractReceiver?: boolean;
  disableSecurityChecks?: boolean;
};

type QuoteRouteShape = {
  providers: ProviderName[];
  sellAsset: string;
  sellAmount: string;
  buyAsset: string;
  expectedBuyAmount: string;
  expectedBuyAmountMaxSlippage?: string;
  sourceAddress?: string;
  destinationAddress?: string;
  refundAddress?: string;
  targetAddress?: string;
  inboundAddress?: string;
  memo?: string;
  expiration?: string;
  fees: Fees; // { type, amount, asset, chain, protocol }[]
  estimatedTime?: EstimatedTime; // { inbound?, swap?, outbound?, total }
  meta?: { priceImpact?: number; slippageBps?: number; totalBps?: number; tags?: string[]; approvalAddress?: string /* ... */ };
  warnings?: { code: string; display: string; tooltip?: string }[];
  legs?: QuoteResponseRouteLeg[];
  tx?: unknown; // EVM tx object, Cosmos tx object or serialized string
  txType?: string;
};

type ProviderNameValues =
  | "THORCHAIN"
  | "THORCHAIN_STREAMING"
  | "CHAINFLIP"
  | "CHAINFLIP_STREAMING"
  | "MAYACHAIN"
  | "MAYACHAIN_STREAMING"
  | "UNISWAP_V2"
  | "UNISWAP_V3"
  | "SUSHISWAP_V2"
  | "PANCAKESWAP"
  | "TRADERJOE_V2"
  | "PANGOLIN_V1"
  | "CAMELOT_V3"
  | "CAVIAR_V1"
  | "OCISWAP_V1"
  | "OPENOCEAN_V2"
  | "JUPITER"
  | "ONEINCH"
  | "OKX"
  | "NEAR"
  | "GARDEN"
  | "HOUDINI";

type PriceRequestShape = {
  tokens: { identifier: string }[];
  metadata: boolean;
};

type PriceResponseShape = {
  identifier?: string;
  price_usd?: number;
  provider?: string;
  timestamp?: number;
  cg?: unknown; // CoinGecko metadata when `metadata: true`
}[];

type TrackingRequestShape =
  | { hash: string; chainId: string; block?: number } // block required for Polkadot
  | { depositChannelId: string };

type ChainBalanceShape = {
  chain: string;
  identifier: string;
  symbol: string;
  ticker: string;
  value: string;
  decimal: number;
}[];
```
