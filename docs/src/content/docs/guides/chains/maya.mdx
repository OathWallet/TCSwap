This guide covers Maya Protocol integration with TCSwap, including wallet connections, CACAO operations, liquidity provision, and cross-chain swaps.

## Overview

Maya Protocol is a fork of THORChain providing cross-chain liquidity with CACAO as its native asset. TCSwap provides Maya Protocol support through:

- **Maya Toolbox**: Native Maya operations with CACAO (built on the THORChain-style Cosmos toolbox)
- **Mayachain Plugin**: Swaps, liquidity provision, node actions and MAYANames via `uSwap.mayachain`
- **Cross-Chain Swaps**: Swaps routed through Maya pools
- **Multi-Wallet Support**: Compatible with keystore, CTRL, Vultisig, KeepKey and WalletConnect

## Getting Started

### Installation

```bash
# Full SDK (recommended)
bun add @tcswap/sdk

# Individual packages for smaller bundles
bun add @tcswap/toolboxes @tcswap/plugins
```

## Maya Toolbox

### Wallet Connection

Connect to Maya Protocol using various wallet types:

```typescript
// @noErrorValidation
import { Chain, FeeOption } from "@tcswap/sdk";

await uSwap.connectKeystore([Chain.Maya], "your mnemonic phrase");

await uSwap.connectCtrl([Chain.Maya]);

await uSwap.connectVultisig([Chain.Maya]);
```

### Address Generation

Maya addresses use bech32 format with "maya" prefix:

```typescript
// @noErrorValidation
import { getCosmosValidateAddress } from "@tcswap/toolboxes/cosmos";

const mayaAddress = uSwap.getAddress(Chain.Maya);

console.log("Maya address:", mayaAddress);

const validateMayaAddress = getCosmosValidateAddress(Chain.Maya);
console.log("Valid CACAO address:", validateMayaAddress(mayaAddress));

const publicKey = await mayaToolbox.getPubKey();
console.log("Maya public key:", publicKey);
```

### CACAO Transfers

```typescript
// @noErrorValidation
import { AssetValue } from "@tcswap/sdk";

const txHash = await uSwap.transfer({
  recipient: "maya1xv9tklw7d82sezh9haa573wufgy59vmwe6xxe5",
  assetValue: AssetValue.from({
    chain: Chain.Maya,
    value: "10",
  }),
  feeOptionKey: FeeOption.Fast,
  memo: "Payment",
});

console.log(`Maya transaction hash: ${txHash}`);

const toolboxTx = await mayaToolbox.transfer({
  recipient: "maya1xv9tklw7d82sezh9haa573wufgy59vmwe6xxe5",
  assetValue: AssetValue.from({ chain: Chain.Maya, value: "5" }),
  memo: "Toolbox transfer",
});

const batchTransfers = async () => {
  const recipients = [
    { address: "maya1xv9tklw7d82sezh9haa573wufgy59vmwe6xxe5", amount: "2" },
    { address: "maya1fl48vsnmsdzcv85q5d2q4z5ajdha8yu34mf0eh", amount: "3" },
    { address: "maya1qypqxpq9qcrsszg2pvxq6rs0zqg3yyc5lzv7xu", amount: "1.5" },
  ];

  for (const { address, amount } of recipients) {
    const tx = await mayaToolbox.transfer({
      recipient: address,
      assetValue: AssetValue.from({ chain: Chain.Maya, value: amount }),
    });
    console.log(`CACAO sent to ${address}: ${tx}`);
  }
};
```

### Deposits (MsgDeposit)

Protocol actions on Maya are sent as a `MsgDeposit` with a memo. The toolbox exposes this as `deposit`:

```typescript
// @noErrorValidation

const depositTx = await mayaToolbox.deposit({
  assetValue: AssetValue.from({ chain: Chain.Maya, value: "1" }),
  memo: "=:BTC.BTC:bc1qxyz...",
});
```

### Node Operations (Maya Validators)

Maya Protocol uses a similar validator system to THORChain. Node data is available from Midgard, and bond/unbond/leave are sent with `nodeAction`:

```typescript
// @noErrorValidation
import { MemoType, USwapApi } from "@tcswap/sdk";

const nodes = await USwapApi.mayachainMidgard.getNodes();
console.log("Maya nodes:", nodes);

const bondTx = await uSwap.mayachain.nodeAction({
  type: MemoType.BOND,
  assetValue: AssetValue.from({ chain: Chain.Maya, value: "1000000" }),
  address: "maya1nodeaddress...",
});

console.log("Node bond successful:", bondTx);

const unbondTx = await uSwap.mayachain.nodeAction({
  type: MemoType.UNBOND,
  assetValue: AssetValue.from({ chain: Chain.Maya, value: "500000" }),
  address: "maya1nodeaddress...",
});

const leaveTx = await uSwap.mayachain.nodeAction({
  type: MemoType.LEAVE,
  address: "maya1nodeaddress...",
});

console.log("Validator leaving:", leaveTx);
```

### Liquidity Operations

Maya Protocol supports liquidity provision similar to THORChain:

```typescript
// @noErrorValidation
import { USwapApi } from "@tcswap/sdk";

const addLiquidity = async () => {
  const cacaoLiquidity = await uSwap.mayachain.addLiquidity({
    baseAssetValue: AssetValue.from({ chain: Chain.Maya, value: "100" }),
    assetValue: AssetValue.from({ asset: "BTC.BTC", value: "0" }),
    baseAssetAddr: uSwap.getAddress(Chain.Maya),
    mode: "baseAsset",
  });

  console.log("CACAO liquidity added:", cacaoLiquidity);

  const symmetricLiquidity = await uSwap.mayachain.addLiquidity({
    baseAssetValue: AssetValue.from({ chain: Chain.Maya, value: "50" }),
    assetValue: AssetValue.from({ asset: "BTC.BTC", value: "0.001" }),
    baseAssetAddr: uSwap.getAddress(Chain.Maya),
    assetAddr: uSwap.getAddress(Chain.Bitcoin),
    mode: "sym",
  });

  console.log("Symmetric liquidity:", {
    cacaoTx: symmetricLiquidity.baseAssetTx,
    btcTx: symmetricLiquidity.assetTx,
  });
};

const withdrawLiquidity = async () => {
  const withdrawal = await uSwap.mayachain.withdraw({
    assetValue: AssetValue.from({ asset: "BTC.BTC", value: "0" }),
    percent: 50,
    from: "sym",
    to: "sym",
  });

  console.log("Liquidity withdrawn:", withdrawal);
};

const getLiquidityPosition = async () => {
  const positions = await USwapApi.mayachainMidgard.getLiquidityPosition(
    uSwap.getAddress(Chain.Maya)
  );

  positions.forEach((position) => {
    console.log("Maya liquidity position:", {
      asset: position.asset,
      cacao: position.cacao,
      poolShare: position.poolShare,
    });
  });
};
```

### Cross-Chain Swaps

Get a quote restricted to Maya providers and execute it with the Mayachain plugin:

```typescript
// @noErrorValidation
import { ProviderName, USwapApi } from "@tcswap/sdk";

const { routes } = await USwapApi.getSwapQuote({
  sellAsset: "MAYA.CACAO",
  sellAmount: "100",
  buyAsset: "BTC.BTC",
  sourceAddress: uSwap.getAddress(Chain.Maya),
  destinationAddress: uSwap.getAddress(Chain.Bitcoin),
  providers: [ProviderName.MAYACHAIN],
});

const [route] = routes;

console.log("Swap quote:", {
  expectedOutput: route.expectedBuyAmount,
  fees: route.fees,
});

const swapTx = await uSwap.swap({
  route,
  feeOptionKey: FeeOption.Fast,
});

console.log("Swap executed:", swapTx);

const usdcToCacao = await USwapApi.getSwapQuote({
  sellAsset: "ETH.USDC-0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48",
  sellAmount: "1000",
  buyAsset: "MAYA.CACAO",
  sourceAddress: uSwap.getAddress(Chain.Ethereum),
  destinationAddress: uSwap.getAddress(Chain.Maya),
  providers: [ProviderName.MAYACHAIN, ProviderName.MAYACHAIN_STREAMING],
});

await uSwap.swap({
  route: usdcToCacao.routes[0],
  feeOptionKey: FeeOption.Average,
});
```

### Maya Names Service

Similar to THORNames, Maya has its own naming service:

```typescript
// @noErrorValidation
import { USwapApi } from "@tcswap/sdk";

const registerMayaName = async () => {
  const mayaName = "myname";

  const registerTx = await uSwap.mayachain.registerName({
    assetValue: AssetValue.from({ chain: Chain.Maya, value: "10.02" }),
    name: mayaName,
    chain: "MAYA",
    address: uSwap.getAddress(Chain.Maya),
    owner: uSwap.getAddress(Chain.Maya),
    preferredAsset: "BTC.BTC",
  });

  console.log(`Registered ${mayaName}:`, registerTx);
};

const updateMayaName = async () => {
  const updateTx = await uSwap.mayachain.registerName({
    assetValue: AssetValue.from({ chain: Chain.Maya, value: "0.02" }),
    name: "myname",
    chain: "BTC",
    address: uSwap.getAddress(Chain.Bitcoin),
    owner: uSwap.getAddress(Chain.Maya),
  });

  console.log("Maya name updated:", updateTx);
};

const lookupMayaName = async () => {
  const nameDetails = await USwapApi.mayachainMidgard.getNameDetails("myname");
  console.log("Maya name details:", nameDetails);

  const ownedNames = await USwapApi.mayachainMidgard.getNamesByOwner(
    uSwap.getAddress(Chain.Maya)
  );
  console.log("Owned names:", ownedNames);
};
```

## Error Handling

Handle Maya-specific errors:

```typescript
// @noErrorValidation
import { USwapError } from "@tcswap/sdk";

try {
  await uSwap.mayachain.addLiquidity({
    /* ... */
  });
} catch (error) {
  if (error instanceof USwapError) {
    const errorKey = error.message.split(":")[0];

    switch (errorKey) {
      case "core_wallet_connection_not_found":
        console.error("Maya wallet is not connected");
        break;
      case "core_chain_halted":
        console.error("Chain is halted on Maya");
        break;
      case "core_transaction_deposit_insufficient_funds_error":
        console.error("Insufficient CACAO balance");
        break;
      case "core_transaction_add_liquidity_invalid_params":
        console.error("Invalid liquidity parameters");
        break;
      case "toolbox_cosmos_no_signer":
        console.error("No signer available for the Maya toolbox");
        break;
      default:
        console.error("Unknown Maya error:", error);
    }
  }
}
```

## API Reference Summary

### Toolbox Methods

- `getAddress()` - Get the signer address
- `getBalance()` - Get balances as `AssetValue[]`
- `getAccount()` - Get Maya account information
- `transfer()` - Send CACAO or other Maya assets
- `deposit()` - Send a `MsgDeposit` with a memo
- `getFees()` - Get fee rates per `FeeOption`
- `validateAddress()` - Validate a Maya address
- `createMultisig()` / `signMultisigTx()` / `broadcastMultisigTx()` - Multisig helpers

### Mayachain Plugin Methods (`uSwap.mayachain`)

- `swap()` - Execute a Maya swap route
- `addLiquidity()` / `addLiquidityPart()` / `createLiquidity()` - Provide liquidity
- `withdraw()` - Withdraw liquidity from pools
- `nodeAction()` - Bond, unbond or leave as a node operator
- `registerName()` / `registerPreferredAsset()` - Manage MAYANames
- `getInboundDataByChain()` - Get inbound vault data for a chain

### Midgard (`USwapApi.mayachainMidgard`)

- `getLiquidityPosition()` - Get current LP positions
- `getNodes()` - Get Maya nodes
- `getNameDetails()` / `getNamesByOwner()` - Look up MAYANames
