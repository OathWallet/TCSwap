This guide covers Bitcoin Cash integration with TCSwap, including wallet connections, UTXO management, CashAddr format, and cross-chain swaps.

## Overview

Bitcoin Cash is a peer-to-peer electronic cash system that focuses on fast, low-cost transactions. TCSwap provides comprehensive Bitcoin Cash support through:

- **Bitcoin Cash Toolbox**: UTXO management with BCH-specific transaction building and signing
- **CashAddr Support**: Modern Bitcoin Cash address format, plus conversion to and from legacy addresses
- **Cross-Chain Swaps**: Seamless swaps with other cryptocurrencies via THORChain
- **Low Transaction Fees**: Optimized for micro-transactions and payments
- **Multi-Wallet Support**: Compatible with hardware and software wallets

## Bitcoin Cash Toolbox

### Wallet Connection

Connect to Bitcoin Cash using various wallet types:

```typescript
// @noErrorValidation
import { Chain, FeeOption } from "@tcswap/sdk";

await uSwap.connectKeystore([Chain.BitcoinCash], "your mnemonic phrase");

await uSwap.connectLedger([Chain.BitcoinCash]);

await uSwap.connectTrezor([Chain.BitcoinCash], [44, 145, 0, 0, 0]);
```

### Address Formats

The toolbox returns CashAddr addresses without the `bitcoincash:` prefix. Use the exported helpers to convert between formats:

```typescript
// @noErrorValidation
import {
  stripPrefix,
  stripToCashAddress,
  toCashAddress,
  toLegacyAddress,
} from "@tcswap/toolboxes/utxo";

const address = await bchToolbox.getAddress();
// e.g. "qp3wjpa3tjlj042z2wv7hahsldgwhwy0rq9sywjpyy"

const cashAddr = "bitcoincash:qp3wjpa3tjlj042z2wv7hahsldgwhwy0rq9sywjpyy";

const legacy = toLegacyAddress(cashAddr);
console.log("Legacy format:", legacy);

const withPrefix = toCashAddress(legacy); // "bitcoincash:q..."
const withoutPrefix = stripToCashAddress(legacy); // "q..."
const stripped = stripPrefix(cashAddr); // "q..."
```

### Bitcoin Cash Transfers

```typescript
// @noErrorValidation
import { AssetValue } from "@tcswap/sdk";

const txHash = await uSwap.transfer({
  recipient: "bitcoincash:qp3wjpa3tjlj042z2wv7hahsldgwhwy0rq9sywjpyy",
  assetValue: AssetValue.from({
    chain: Chain.BitcoinCash,
    value: "0.01",
  }),
  feeOptionKey: FeeOption.Fast,
});

console.log(`Bitcoin Cash transaction hash: ${txHash}`);

const microPayment = await bchToolbox.transfer({
  recipient: "bitcoincash:qp3wjpa3tjlj042z2wv7hahsldgwhwy0rq9sywjpyy",
  assetValue: AssetValue.from({ chain: Chain.BitcoinCash, value: "0.0001" }),
  feeRate: 1,
});

const batchPayments = async () => {
  const recipients = [
    {
      address: "bitcoincash:qp3wjpa3tjlj042z2wv7hahsldgwhwy0rq9sywjpyy",
      amount: "0.001",
    },
    {
      address: "bitcoincash:qzgpa8j0krfnh9t6qefqp6nq8zqz5zh8tqp7qvqv77",
      amount: "0.002",
    },
  ];

  for (const { address, amount } of recipients) {
    const tx = await bchToolbox.transfer({
      recipient: address,
      assetValue: AssetValue.from({ chain: Chain.BitcoinCash, value: amount }),
      feeRate: 1,
    });
    console.log(`Payment to ${address}: ${tx}`);
  }
};
```

### UTXO Management

UTXO selection happens automatically in `transfer()`. To build a transaction yourself, `buildTx()` returns an unsigned PSBT with the selected inputs:

```typescript
// @noErrorValidation
import { getUtxoApi, stripToCashAddress } from "@tcswap/toolboxes/utxo";

const sender = await bchToolbox.getAddress();

const utxos = await getUtxoApi(Chain.BitcoinCash).getUtxos({
  address: stripToCashAddress(sender),
});

utxos.forEach((utxo, index) => {
  console.log(`UTXO ${index}: ${utxo.value} sats (${utxo.hash}:${utxo.index})`);
});

const { psbt, inputs } = await bchToolbox.buildTx({
  sender,
  recipient: "bitcoincash:qp3wjpa3tjlj042z2wv7hahsldgwhwy0rq9sywjpyy",
  assetValue: AssetValue.from({ chain: Chain.BitcoinCash, value: "0.005" }),
  feeRate: 2,
});

console.log(`Selected ${inputs.length} inputs`);
```

### Fee Management

Bitcoin Cash has consistently low fees:

```typescript
// @noErrorValidation

const feeRates = await bchToolbox.getFeeRates();
console.log({
  average: feeRates[FeeOption.Average],
  fast: feeRates[FeeOption.Fast],
  fastest: feeRates[FeeOption.Fastest],
});

const sender = await bchToolbox.getAddress();

const fee = await bchToolbox.estimateTransactionFee({
  sender,
  recipient: "bitcoincash:qp3wjpa3tjlj042z2wv7hahsldgwhwy0rq9sywjpyy",
  assetValue: AssetValue.from({ chain: Chain.BitcoinCash, value: "0.1" }),
  feeOptionKey: FeeOption.Fast,
});

console.log(`Estimated fee: ${fee.getValue("string")} BCH`);
```

### Balances

`getBalance` accepts CashAddr (with or without prefix) or legacy addresses:

```typescript
// @noErrorValidation

const balances = await bchToolbox.getBalance(
  "bitcoincash:qp3wjpa3tjlj042z2wv7hahsldgwhwy0rq9sywjpyy"
);
const bchBalance = balances.find((asset) => asset.isGasAsset);

console.log(`Balance: ${bchBalance?.getValue("string")} BCH`);
```

## Cross-Chain Swaps

Bitcoin Cash is supported in THORChain cross-chain swaps:

```typescript
// @noErrorValidation
import { USwapApi } from "@tcswap/sdk";

const { routes } = await USwapApi.getSwapQuote({
  sellAsset: "BCH.BCH",
  sellAmount: "1",
  buyAsset: "BTC.BTC",
  sourceAddress: uSwap.getAddress(Chain.BitcoinCash),
  destinationAddress: uSwap.getAddress(Chain.Bitcoin),
});

const [bestRoute] = routes;

console.log("BCH -> BTC quote:", {
  expectedOutput: bestRoute.expectedBuyAmount,
  fees: bestRoute.fees,
  estimatedTime: bestRoute.estimatedTime,
});

const swapTx = await uSwap.swap({
  route: bestRoute,
  feeOptionKey: FeeOption.Fast,
});

const bchToUsdtQuote = await USwapApi.getSwapQuote({
  sellAsset: "BCH.BCH",
  sellAmount: "0.5",
  buyAsset: "ETH.USDT-0xdAC17F958D2ee523a2206206994597C13D831ec7",
  sourceAddress: uSwap.getAddress(Chain.BitcoinCash),
  destinationAddress: uSwap.getAddress(Chain.Ethereum),
});

const bchToRuneQuote = await USwapApi.getSwapQuote({
  sellAsset: "BCH.BCH",
  sellAmount: "0.1",
  buyAsset: "THOR.RUNE",
  sourceAddress: uSwap.getAddress(Chain.BitcoinCash),
  destinationAddress: uSwap.getAddress(Chain.THORChain),
});
```

## Network Configuration

### UTXO Data Provider

Bitcoin Cash balances, UTXOs and fee rates come from Blockchair. Set an API key to avoid rate limits; `blockchairApiUrl` in `envs` can point the requests at your own proxy:

```typescript
// @noErrorValidation
import { USwapConfig } from "@tcswap/sdk";

USwapConfig.setApiKey("blockchair", "your-blockchair-api-key");
```

## Error Handling

Handle Bitcoin Cash specific errors:

```typescript
// @noErrorValidation
import { USwapError } from "@tcswap/sdk";

try {
  await uSwap.transfer({
    /* ... */
  });
} catch (error) {
  if (error instanceof USwapError) {
    const errorKey = error.message.split(":")[0];

    switch (errorKey) {
      case "toolbox_utxo_insufficient_balance":
        console.error("Insufficient Bitcoin Cash balance");
        break;
      case "toolbox_utxo_invalid_address":
        console.error("Invalid Bitcoin Cash address");
        break;
      case "toolbox_utxo_no_signer":
        console.error("No signer configured for this toolbox");
        break;
      case "toolbox_utxo_api_error":
        console.error("UTXO data provider error:", error.cause);
        break;
      default:
        console.error("Unknown Bitcoin Cash error:", error);
    }
  }
}
```

## Best Practices

1. **Use CashAddr Format**:

   ```typescript
   const cashAddr = "bitcoincash:qp3wjpa3tjlj042z2wv7hahsldgwhwy0rq9sywjpyy";
   const legacy = "1KXrWXciRDrSAvuajXN8u4vBKbLQ9xhNSa";
   ```

2. **Leverage Low Fees**:

   ```typescript
   await bchToolbox.transfer({
     recipient: "bitcoincash:qp3wjpa3tjlj042z2wv7hahsldgwhwy0rq9sywjpyy",
     assetValue: AssetValue.from({ chain: Chain.BitcoinCash, value: "0.0001" }),
     feeOptionKey: FeeOption.Average,
   });
   ```

3. **Validate Addresses**:

   ```typescript
   import { bchValidateAddress } from "@tcswap/toolboxes/utxo";

   const recipient = "bitcoincash:qp3wjpa3tjlj042z2wv7hahsldgwhwy0rq9sywjpyy";
   if (!bchValidateAddress(recipient)) {
     throw new Error("Invalid Bitcoin Cash address");
   }
   ```

## Address Validation

`bchValidateAddress` accepts mainnet CashAddr (with or without the `bitcoincash:` prefix) and legacy addresses:

```typescript
// @noErrorValidation
import { bchValidateAddress } from "@tcswap/toolboxes/utxo";

const testAddresses = [
  "bitcoincash:qp3wjpa3tjlj042z2wv7hahsldgwhwy0rq9sywjpyy",
  "qp3wjpa3tjlj042z2wv7hahsldgwhwy0rq9sywjpyy",
  "1KXrWXciRDrSAvuajXN8u4vBKbLQ9xhNSa",
  "invalid_address",
];

testAddresses.forEach((address) => {
  const isValid = bchValidateAddress(address);
  console.log(`${address}: ${isValid ? "Valid" : "Invalid"}`);
});
```

## Troubleshooting

### Common Issues

1. **Address format confusion**: some services only accept legacy addresses. Convert with `toLegacyAddress(address)`, or back with `toCashAddress(address)`.

2. **Dust limit issues**:

   ```typescript
   const dustLimit = 550; // BCH dust threshold used by the UTXO toolbox

   const checkDustLimit = (amount: string) => {
     const sats = parseFloat(amount) * 100000000;
     if (sats < dustLimit) {
       console.error(
         `Amount ${sats} sats below dust limit of ${dustLimit} sats`
       );
       return false;
     }
     return true;
   };
   ```

## API Reference Summary

### Core Methods

- `getBalance(address)` - Get balances as `AssetValue[]`
- `transfer()` - Send BCH with automatic UTXO selection
- `buildTx()` - Build an unsigned PSBT with selected inputs
- `createTransaction()` - Build a BCH `TransactionBuilder` with selected UTXOs
- `broadcastTx(txHex)` - Broadcast a signed raw transaction

### Address Methods

- `getAddress()` - CashAddr address (without prefix) of the configured signer
- `validateAddress()` / `bchValidateAddress()` - Validate a BCH address
- `toCashAddress()` / `toLegacyAddress()` - Convert between address formats
- `stripPrefix()` / `stripToCashAddress()` - Normalize CashAddr strings

### Fee Management

- `getFeeRates()` - Get current fee rates per `FeeOption` (typically very low)
- `estimateTransactionFee()` - Estimate fee for a transaction
- `estimateMaxSendableAmount()` - Balance minus estimated fee
