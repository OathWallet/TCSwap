This guide covers Solana integration with TCSwap, including wallet connections, SOL transfers, SPL token operations, and cross-chain swaps.

## Overview

Solana is a high-performance blockchain known for fast transactions and low fees. TCSwap provides Solana support through:

- **Solana Toolbox**: Native SOL transfers, balance queries, transaction signing and broadcasting
- **SPL Token Support**: Transfers of Solana's token standard
- **Cross-Chain Swaps**: Swaps with other cryptocurrencies, plus Jupiter routing on Solana via the Solana plugin
- **Program Interaction**: Build transactions from your own program instructions
- **Multi-Wallet Support**: Compatible with Phantom, CTRL, Bitget, OneKey, Vultisig and keystore wallets

## Solana Toolbox

### Wallet Connection

Connect to Solana using various wallet types:

```typescript
// @noErrorValidation
import { Chain, FeeOption } from "@tcswap/sdk";

await uSwap.connectKeystore([Chain.Solana], "your mnemonic phrase");

await uSwap.connectPhantom([Chain.Solana]);

await uSwap.connectCtrl([Chain.Solana]);
```

### Address Generation

Solana addresses are base58-encoded public keys:

```typescript
// @noErrorValidation
import { getSolanaAddressValidator } from "@tcswap/toolboxes/solana";

const solanaAddress = uSwap.getAddress(Chain.Solana);

console.log("Solana address:", solanaAddress);

const validateSolanaAddress = await getSolanaAddressValidator();

const isValidAddress = validateSolanaAddress(solanaAddress);
console.log("Valid SOL address:", isValidAddress);

const toolboxAddress = solToolbox.getAddress();
const publicKey = await solToolbox.getPubkeyFromAddress(toolboxAddress);
console.log("Public key:", publicKey.toBase58());
```

### SOL Transfers

```typescript
// @noErrorValidation
import { AssetValue } from "@tcswap/sdk";

const txHash = await uSwap.transfer({
  recipient: "9WzDXwBbmkg8ZTbNMqUxvQRAyrZzDsGYdLVL9zYtAWWM",
  assetValue: AssetValue.from({
    chain: Chain.Solana,
    value: "0.1",
  }),
  feeOptionKey: FeeOption.Fast,
  memo: "Payment for services",
});

console.log(`Solana transaction signature: ${txHash}`);

const toolboxTx = await solToolbox.transfer({
  recipient: "9WzDXwBbmkg8ZTbNMqUxvQRAyrZzDsGYdLVL9zYtAWWM",
  assetValue: AssetValue.from({ chain: Chain.Solana, value: "0.05" }),
  memo: "Toolbox transfer",
});
```

### SPL Token Operations

Solana Program Library (SPL) tokens are equivalent to ERC-20 on Ethereum. Transfers create the recipient's associated token account when needed:

```typescript
// @noErrorValidation

const usdcTransfer = await uSwap.transfer({
  recipient: "9WzDXwBbmkg8ZTbNMqUxvQRAyrZzDsGYdLVL9zYtAWWM",
  assetValue: AssetValue.from({
    chain: Chain.Solana,
    symbol: "USDC",
    address: "EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v",
    value: "100",
  }),
  feeOptionKey: FeeOption.Average,
});

// Returns SOL plus all SPL token balances as AssetValue[]
const balances = await solToolbox.getBalance(
  "9WzDXwBbmkg8ZTbNMqUxvQRAyrZzDsGYdLVL9zYtAWWM"
);

const usdc = balances.find(
  (asset) => asset.address === "EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v"
);
console.log(`USDC balance: ${usdc?.getValue("string") ?? "0"} USDC`);
```

### Program Interactions

Build a transaction from your own program instructions, then sign and broadcast it with the toolbox:

```typescript
// @noErrorValidation
import { PublicKey, TransactionInstruction } from "@solana/web3.js";

const instruction = new TransactionInstruction({
  programId: new PublicKey("MemoSq4gqABAXKb96qnH8TysNcWxMyWCqXgDLGmfcHr"),
  keys: [],
  data: Buffer.from("hello from TCSwap"),
});

const transaction = await solToolbox.createTransactionFromInstructions({
  instructions: [instruction],
});

const signedTransaction = await solToolbox.signTransaction(transaction);
const signature = await solToolbox.broadcastTransaction(signedTransaction);

console.log("Transaction signature:", signature);
```

### Fee Estimation

```typescript
// @noErrorValidation

const fee = await solToolbox.estimateTransactionFee({
  recipient: "9WzDXwBbmkg8ZTbNMqUxvQRAyrZzDsGYdLVL9zYtAWWM",
  assetValue: AssetValue.from({ chain: Chain.Solana, value: "0.1" }),
  sender: solToolbox.getAddress(),
});

console.log(`Estimated fee: ${fee.getValue("string")} SOL`);
```

### Transaction Status

The toolbox exposes the underlying `@solana/web3.js` connection for anything not wrapped directly:

```typescript
// @noErrorValidation

const connection = await solToolbox.getConnection();

const status = await connection.getSignatureStatus(signature);
console.log("Confirmation status:", status.value?.confirmationStatus);

const txDetails = await connection.getTransaction(signature, {
  maxSupportedTransactionVersion: 0,
});
console.log("Fee paid (lamports):", txDetails?.meta?.fee);
```

## Cross-Chain Swaps

Solana is supported in cross-chain swaps via various protocols. Quotes come from the TCSwap API; `uSwap.swap` executes the selected route with the matching plugin:

```typescript
// @noErrorValidation
import { USwapApi } from "@tcswap/sdk";

const { routes } = await USwapApi.getSwapQuote({
  sellAsset: "SOL.SOL",
  sellAmount: "10",
  buyAsset: "BTC.BTC",
  sourceAddress: uSwap.getAddress(Chain.Solana),
  destinationAddress: uSwap.getAddress(Chain.Bitcoin),
});

const [bestRoute] = routes;

console.log("SOL -> BTC quote:", {
  expectedOutput: bestRoute.expectedBuyAmount,
  fees: bestRoute.fees,
  timeEstimate: bestRoute.estimatedTime,
});

const swapTx = await uSwap.swap({
  route: bestRoute,
  feeOptionKey: FeeOption.Fast,
});

const { routes: jupiterRoutes } = await USwapApi.getSwapQuote({
  sellAsset: "SOL.SOL",
  sellAmount: "5",
  buyAsset: "SOL.USDC-EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v",
  sourceAddress: uSwap.getAddress(Chain.Solana),
  destinationAddress: uSwap.getAddress(Chain.Solana),
  providers: ["JUPITER"],
});

// Executed by the Solana plugin (signs and broadcasts the Jupiter transaction)
const jupiterSwap = await uSwap.swap({ route: jupiterRoutes[0] });
```

## Error Handling

Handle Solana-specific errors:

```typescript
// @noErrorValidation
import { USwapError } from "@tcswap/sdk";

try {
  await uSwap.transfer({
    /* ... */
  });
} catch (error) {
  if (error instanceof USwapError) {
    switch (error.message.split(":")[0]) {
      case "core_transaction_deposit_insufficient_funds_error":
        console.error("Insufficient SOL balance");
        break;
      case "core_transaction_invalid_recipient_address":
        console.error("Invalid Solana address format");
        break;
      case "toolbox_solana_broadcast_failed":
        console.error("Transaction failed:", error.cause);
        break;
      case "toolbox_solana_no_signer":
        console.error("No signer available");
        break;
      case "toolbox_solana_fee_estimation_failed":
        console.error("Could not estimate fee");
        break;
      default:
        console.error("Unknown Solana error:", error);
    }
  }
}
```

## Best Practices

1. **Validate addresses** before sending:

   ```typescript
   const validateSolanaAddress = await getSolanaAddressValidator();

   if (!validateSolanaAddress(recipient)) {
     throw new Error("Invalid Solana address");
   }
   ```

2. **Use `isProgramDerivedAddress`** when sending to a program-derived address (PDA), which is off-curve and would otherwise fail address validation:

   ```typescript
   await solToolbox.transfer({
     recipient: pdaAddress,
     assetValue: AssetValue.from({ chain: Chain.Solana, value: "0.1" }),
     isProgramDerivedAddress: true,
   });
   ```

3. **Estimate fees** before sending to make sure the account keeps enough SOL for rent and fees.

## API Reference Summary

### Core Methods

- `getBalance(address?)` - Get SOL and SPL token balances
- `transfer()` - Send SOL or SPL tokens
- `estimateTransactionFee()` - Estimate the fee for a transfer
- `getAddress()` - Address of the configured signer

### Transaction Methods

- `createTransaction()` - Build a SOL/SPL transfer transaction
- `createTransactionFromInstructions()` - Build a transaction from custom instructions
- `signTransaction()` - Sign a transaction with the configured signer
- `broadcastTransaction()` - Send a signed transaction
- `getConnection()` - Underlying `@solana/web3.js` connection

### Key and Address Methods

- `createKeysForPath()` - Derive a keypair from a phrase
- `getAddressFromPubKey()` / `getPubkeyFromAddress()` - Convert between addresses and public keys
- `getAddressValidator()` - Get an address validator function
