This guide covers XRP Ledger integration with TCSwap, including wallet connections, XRP transfers, trustlines, and cross-chain swaps.

## Overview

XRP Ledger is a decentralized blockchain focused on fast, low-cost payments and remittances. TCSwap provides XRP Ledger support through:

- **Ripple Toolbox**: Native XRP payments with sub-second settlement
- **Memos**: Attach memo data to payments
- **Cross-Chain Swaps**: Swap XRP with other cryptocurrencies
- **Multi-Wallet Support**: Compatible with Xaman, Ledger and keystore wallets

The toolbox currently supports native XRP only; issued currencies (trustline tokens) throw `toolbox_ripple_asset_not_supported`.

## Getting Started

### Installation

```bash
# Full SDK (recommended)
bun add @tcswap/sdk

# Individual packages for smaller bundles
bun add @tcswap/toolboxes @tcswap/plugins
```

## XRP Toolbox

### Wallet Connection

Connect to XRP Ledger using various wallet types:

```typescript
// @noErrorValidation
import { Chain, FeeOption, USwapConfig } from "@tcswap/sdk";

await uSwap.connectKeystore([Chain.Ripple], "your mnemonic phrase");

// Xaman requires an API key (or pass { apiKey } as the second argument)
USwapConfig.setApiKey("xaman", "your-xaman-api-key");
await uSwap.connectXaman([Chain.Ripple]);

await uSwap.connectLedger([Chain.Ripple]);
```

### Address Generation and Validation

XRP addresses are base58-encoded and start with 'r':

```typescript
// @noErrorValidation
import { rippleValidateAddress } from "@tcswap/toolboxes/ripple";

const xrpAddress = uSwap.getAddress(Chain.Ripple);

console.log("XRP address:", xrpAddress);

const isValidAddress = rippleValidateAddress(xrpAddress);
console.log("Valid XRP address:", isValidAddress);

const [xrpBalance] = await xrpToolbox.getBalance(xrpAddress);
console.log("Balance:", xrpBalance.getValue("string"), "XRP");
```

### XRP Transfers

```typescript
// @noErrorValidation
import { AssetValue } from "@tcswap/sdk";

const txHash = await uSwap.transfer({
  recipient: "rN7n7otQDd6FczFgLdSqtcsAUxDkw6fzRH",
  assetValue: AssetValue.from({
    chain: Chain.Ripple,
    value: "10",
  }),
  feeOptionKey: FeeOption.Fast,
  memo: "Payment reference: INV-001",
});

console.log(`XRP transaction hash: ${txHash}`);

const toolboxTx = await xrpToolbox.transfer({
  recipient: "rN7n7otQDd6FczFgLdSqtcsAUxDkw6fzRH",
  assetValue: AssetValue.from({ chain: Chain.Ripple, value: "5" }),
  memo: "Toolbox XRP transfer",
});
```

### Building and Signing Transactions

`createTransaction` builds a `Payment` and autofills fee, sequence and last ledger sequence from the network. Sign it and submit the resulting blob:

```typescript
// @noErrorValidation

const preparedTx = await xrpToolbox.createTransaction({
  recipient: "rN7n7otQDd6FczFgLdSqtcsAUxDkw6fzRH",
  assetValue: AssetValue.from({ chain: Chain.Ripple, value: "1" }),
  memo: "Signed separately",
});

const { tx_blob, hash } = await xrpToolbox.signTransaction(preparedTx);

// Waits for validation and returns the transaction hash
const confirmedHash = await xrpToolbox.broadcastTransaction(tx_blob);
```

### Fee Estimation

```typescript
// @noErrorValidation

const fee = await xrpToolbox.estimateTransactionFee();
console.log(`Current open ledger fee: ${fee.getValue("string")} XRP`);
```

## Cross-Chain Swaps

XRP is supported in various cross-chain protocols:

```typescript
// @noErrorValidation
import { USwapApi } from "@tcswap/sdk";

const { routes } = await USwapApi.getSwapQuote({
  sellAsset: "XRP.XRP",
  sellAmount: "1000",
  buyAsset: "BTC.BTC",
  sourceAddress: uSwap.getAddress(Chain.Ripple),
  destinationAddress: uSwap.getAddress(Chain.Bitcoin),
});

console.log("XRP -> BTC quote:", {
  expectedOutput: routes[0].expectedBuyAmount,
  fees: routes[0].fees,
  timeEstimate: routes[0].estimatedTime,
});

const swapTx = await uSwap.swap({
  route: routes[0],
  feeOptionKey: FeeOption.Fast,
});
```

## Error Handling

```typescript
// @noErrorValidation
import { USwapError } from "@tcswap/sdk";

try {
  await xrpToolbox.transfer({
    /* ... */
  });
} catch (error) {
  if (error instanceof USwapError) {
    switch (error.message.split(":")[0]) {
      case "toolbox_ripple_signer_not_found":
        console.error("No signer available");
        break;
      case "core_transaction_invalid_recipient_address":
        console.error("Invalid XRP address");
        break;
      case "toolbox_ripple_asset_not_supported":
        console.error("Only native XRP is supported");
        break;
      case "toolbox_ripple_broadcast_error":
        console.error("Transaction was not validated");
        break;
      case "toolbox_ripple_rpc_not_configured":
        console.error("No XRPL RPC URL configured");
        break;
      default:
        console.error("Unknown error:", error);
    }
  }
}
```

## Best Practices

1. **Validate addresses** before sending:

   ```typescript
   import { rippleValidateAddress } from "@tcswap/toolboxes/ripple";

   if (!rippleValidateAddress(recipient)) {
     throw new Error("Invalid XRP address");
   }
   ```

2. **Mind the account reserve**: XRPL accounts must keep a base reserve, so do not try to send the full balance returned by `getBalance`.

3. **Disconnect** standalone toolboxes with `disconnect()` once finished to close the XRPL client connection.

## API Reference Summary

### Core Methods

- `getBalance(address?)` - Get XRP balance
- `transfer()` - Send XRP payments
- `estimateTransactionFee()` - Get the current open ledger fee
- `getAddress()` - Address of the configured signer
- `validateAddress()` - Validate an XRP address

### Transaction Methods

- `createTransaction()` - Build and autofill a payment
- `signTransaction()` - Sign a transaction (returns `{ tx_blob, hash }`)
- `broadcastTransaction()` - Submit a signed blob and wait for validation

### Utilities

- `createSigner(phrase)` - Create a signer from a phrase
- `signer` - The configured signer instance
- `disconnect()` - Close the XRPL client connection
- `rippleValidateAddress()` - Standalone address validator
