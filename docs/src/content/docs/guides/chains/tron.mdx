This guide covers Tron integration with TCSwap, including wallet connections, TRX transfers, TRC-20 token operations, and cross-chain swaps.

## Overview

Tron is a blockchain platform designed for high throughput and smart contract support. TCSwap provides Tron support through:

- **Tron Toolbox**: Native Tron operations with TRX token
- **TRC-20 Support**: Transfers, balances and approvals for Tron's token standard
- **Energy/Bandwidth Aware Fees**: Fee estimation that accounts for the account's available resources
- **Smart Contract Interaction**: Direct access to the underlying `TronWeb` instance
- **Multi-Wallet Support**: Compatible with TronLink, OKX, Ledger and keystore wallets

## Tron Toolbox

### Wallet Connection

Connect to Tron using various wallet types:

```typescript
// @noErrorValidation
import { Chain, FeeOption } from "@tcswap/sdk";

await uSwap.connectKeystore([Chain.Tron], "your mnemonic phrase");

await uSwap.connectTronLink([Chain.Tron]);

await uSwap.connectLedger([Chain.Tron]);
```

### Address Generation and Validation

Tron addresses start with 'T' and are base58-encoded:

```typescript
// @noErrorValidation
import { getTronAddressValidator } from "@tcswap/toolboxes/tron";

const tronAddress = uSwap.getAddress(Chain.Tron);

console.log("Tron address:", tronAddress);

const validateTronAddress = await getTronAddressValidator();

const isValidAddress = validateTronAddress(tronAddress);
console.log("Valid TRX address:", isValidAddress);

// The toolbox exposes the same validator
console.log(tronToolbox.validateAddress(tronAddress));
```

### TRX Transfers

```typescript
// @noErrorValidation
import { AssetValue } from "@tcswap/sdk";

const txHash = await uSwap.transfer({
  recipient: "TLyqzVGLV1srkB7dToTAEqgDSfPtXRJZYH",
  assetValue: AssetValue.from({
    chain: Chain.Tron,
    value: "100",
  }),
  feeOptionKey: FeeOption.Fast,
  memo: "TRX payment",
});

console.log(`Tron transaction hash: ${txHash}`);

const toolboxTransfer = await tronToolbox.transfer({
  recipient: "TLyqzVGLV1srkB7dToTAEqgDSfPtXRJZYH",
  assetValue: AssetValue.from({ chain: Chain.Tron, value: "50" }),
  memo: "Toolbox transfer",
});
```

### TRC-20 Token Operations

Tron's TRC-20 tokens are similar to ERC-20 but with different resource model:

```typescript
// @noErrorValidation

const usdtTransfer = await uSwap.transfer({
  recipient: "TLyqzVGLV1srkB7dToTAEqgDSfPtXRJZYH",
  assetValue: AssetValue.from({
    chain: Chain.Tron,
    symbol: "USDT",
    address: "TR7NHqjeKQxGTCi8q8ZY4pL8otSzgjLj6t",
    value: "100",
  }),
  feeOptionKey: FeeOption.Average,
});

// Returns TRX plus TRC-20 balances as AssetValue[]
const balances = await tronToolbox.getBalance("TLyqzVGLV1srkB7dToTAEqgDSfPtXRJZYH");

balances.forEach((asset) => {
  console.log(`${asset.ticker}: ${asset.getValue("string")} (${asset.address ?? "native"})`);
});
```

### Token Approvals

TRC-20 tokens require approvals before they can be spent by contracts:

```typescript
// @noErrorValidation

const owner = await tronToolbox.getAddress();

const isApproved = await tronToolbox.isApproved({
  assetAddress: "TR7NHqjeKQxGTCi8q8ZY4pL8otSzgjLj6t",
  spenderAddress: "TSpenderContractAddress...",
  from: owner,
  amount: "100000000",
});

if (!isApproved) {
  const approveTx = await tronToolbox.approve({
    assetAddress: "TR7NHqjeKQxGTCi8q8ZY4pL8otSzgjLj6t",
    spenderAddress: "TSpenderContractAddress...",
    amount: "100000000",
  });

  console.log(`Approval transaction: ${approveTx}`);
}

const allowance = await tronToolbox.getApprovedAmount({
  assetAddress: "TR7NHqjeKQxGTCi8q8ZY4pL8otSzgjLj6t",
  spenderAddress: "TSpenderContractAddress...",
  from: owner,
});
```

### Fee Estimation

Fees are estimated from the sender's available bandwidth and energy, the chain parameters, and whether the recipient account needs activation:

```typescript
// @noErrorValidation

const fee = await tronToolbox.estimateTransactionFee({
  recipient: "TLyqzVGLV1srkB7dToTAEqgDSfPtXRJZYH",
  assetValue: AssetValue.from({
    chain: Chain.Tron,
    symbol: "USDT",
    address: "TR7NHqjeKQxGTCi8q8ZY4pL8otSzgjLj6t",
    value: "100",
  }),
});

console.log(`Estimated fee: ${fee.getValue("string")} TRX`);
```

### Building and Signing Transactions

```typescript
// @noErrorValidation

const transaction = await tronToolbox.createTransaction({
  recipient: "TLyqzVGLV1srkB7dToTAEqgDSfPtXRJZYH",
  assetValue: AssetValue.from({ chain: Chain.Tron, value: "10" }),
  sender: await tronToolbox.getAddress(),
  memo: "Signed separately",
});

const signedTx = await tronToolbox.signTransaction(transaction);
const txId = await tronToolbox.broadcastTransaction(signedTx);
```

### Smart Contract Interactions

For contract calls not wrapped by the toolbox, use the underlying `TronWeb` instance together with the exported `trc20ABI`:

```typescript
// @noErrorValidation
import { trc20ABI } from "@tcswap/toolboxes/tron";

const contract = tronToolbox.tronWeb.contract(
  trc20ABI,
  "TR7NHqjeKQxGTCi8q8ZY4pL8otSzgjLj6t"
);

const [balance] = await contract.methods
  .balanceOf("TLyqzVGLV1srkB7dToTAEqgDSfPtXRJZYH")
  .call();

console.log("Raw USDT balance:", balance.toString());

const resources = await tronToolbox.tronWeb.trx.getAccountResources(
  "TLyqzVGLV1srkB7dToTAEqgDSfPtXRJZYH"
);
console.log("Account resources:", resources);
```

## Cross-Chain Operations

Tron tokens can be bridged to other networks:

```typescript
// @noErrorValidation
import { USwapApi } from "@tcswap/sdk";

const { routes } = await USwapApi.getSwapQuote({
  sellAsset: "TRON.TRX",
  sellAmount: "10000",
  buyAsset: "BTC.BTC",
  sourceAddress: uSwap.getAddress(Chain.Tron),
  destinationAddress: uSwap.getAddress(Chain.Bitcoin),
});

console.log("TRX -> BTC quote:", {
  expectedOutput: routes[0].expectedBuyAmount,
  fees: routes[0].fees,
  timeEstimate: routes[0].estimatedTime,
});

const { routes: usdtRoutes } = await USwapApi.getSwapQuote({
  sellAsset: "TRON.USDT-TR7NHqjeKQxGTCi8q8ZY4pL8otSzgjLj6t",
  sellAmount: "1000",
  buyAsset: "ETH.USDT-0xdAC17F958D2ee523a2206206994597C13D831ec7",
  sourceAddress: uSwap.getAddress(Chain.Tron),
  destinationAddress: uSwap.getAddress(Chain.Ethereum),
});

const bridgeTx = await uSwap.swap({
  route: usdtRoutes[0],
  feeOptionKey: FeeOption.Fast,
});
```

## Error Handling

```typescript
// @noErrorValidation
import { USwapError } from "@tcswap/sdk";

try {
  await tronToolbox.transfer({
    /* ... */
  });
} catch (error) {
  if (error instanceof USwapError) {
    switch (error.message.split(":")[0]) {
      case "toolbox_tron_no_signer":
        console.error("No signer available");
        break;
      case "toolbox_tron_token_transfer_failed":
        console.error("Transfer failed:", error.cause);
        break;
      case "toolbox_tron_fee_estimation_failed":
        console.error("Could not estimate fee");
        break;
      case "toolbox_tron_approve_failed":
        console.error("Approval failed");
        break;
      case "toolbox_tron_trongrid_api_error":
        console.error("TronGrid API error");
        break;
      default:
        console.error("Unknown error:", error);
    }
  }
}
```

## Best Practices

1. **Validate addresses** before sending:

   ```typescript
   const validateTronAddress = await getTronAddressValidator();

   if (!validateTronAddress(recipient)) {
     throw new Error("Invalid Tron address");
   }
   ```

2. **Estimate fees before TRC-20 transfers**: transfers to unactivated accounts and transfers without enough energy burn TRX, so check `estimateTransactionFee` against the TRX balance first.

3. **Check approvals** with `isApproved` before calling contracts that spend TRC-20 tokens.

## API Reference Summary

### Core Methods

- `getBalance(address)` - Get TRX and TRC-20 balances
- `transfer()` - Send TRX or TRC-20 tokens
- `estimateTransactionFee()` - Estimate fee including bandwidth, energy and activation
- `getAddress()` - Address of the configured signer
- `validateAddress()` - Validate a Tron address

### Transaction Methods

- `createTransaction()` - Build an unsigned transaction
- `signTransaction()` - Sign a transaction
- `broadcastTransaction()` - Broadcast a signed transaction

### TRC-20 Approval Methods

- `approve()` - Approve a spender
- `isApproved()` - Check approval status
- `getApprovedAmount()` - Get current allowance

### Utilities

- `tronWeb` - Underlying `TronWeb` instance
- `getTronAddressValidator()` - Create an address validator
- `getTronPrivateKeyFromMnemonic()` - Derive a private key from a phrase
- `trc20ABI` - TRC-20 contract ABI
