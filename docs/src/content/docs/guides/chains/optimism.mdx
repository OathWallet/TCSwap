This guide covers Optimism integration with TCSwap, including wallet connections, token transfers, cross-chain swaps, and Optimism-specific features.

## Overview

Optimism is an Ethereum Layer 2 scaling solution using optimistic rollups for fast, cheap transactions. TCSwap provides comprehensive Optimism support through:

- **Optimism Toolbox**: Fast operations with minimal ETH gas costs on L2
- **Cross-Chain Bridging**: Seamless transfers between Ethereum and Optimism
- **DEX Integration**: Access to Velodrome, Uniswap V3, and other Optimism DEXs
- **ERC-20 Compatibility**: Full support for Optimism's token ecosystem
- **Multi-Wallet Support**: Compatible with MetaMask and other Ethereum wallets

## Optimism Toolbox

### Wallet Connection

Connect to Optimism using Ethereum-compatible wallets:

```typescript
// @noErrorValidation
import { Chain, FeeOption } from "@tcswap/sdk";

await uSwap.connectKeystore([Chain.Optimism], "your mnemonic phrase");

await uSwap.connectEVMWallet([Chain.Optimism]);

await uSwap.connectWalletconnect([Chain.Optimism]);

await uSwap.connectLedger([Chain.Optimism]);
```

### Native ETH Transfers

ETH on Optimism is the same as Ethereum ETH, just on Layer 2:

```typescript
// @noErrorValidation
import { AssetValue } from "@tcswap/sdk";

const txHash = await uSwap.transfer({
  recipient: "0x742c4B4F3e0b5b069F5DCF8A65Eaf8d3E888a3E7",
  assetValue: AssetValue.from({
    chain: Chain.Optimism,
    value: "0.1",
  }),
  feeOptionKey: FeeOption.Fast,
});

console.log(`Transaction hash: ${txHash}`);
```

```typescript
  VELO: "0x3c8B650257cFb5f272f799F5e2b4e65093a11a05",
};

const getOptimismPortfolio = async () => {
  const balances = {};
  const address = uSwap.getAddress(Chain.Optimism);

  // Returns the native balance plus every token the address holds as AssetValue[]
  const assetValues = await toolbox.getBalance(address);

  for (const [symbol, tokenAddress] of Object.entries(optimismTokens)) {
    const balance = assetValues.find(
      (asset) => asset.address?.toLowerCase() === tokenAddress.toLowerCase()
    );
    balances[symbol] = balance?.toSignificant(6) ?? "0";
  }

  return balances;
};
```

## Error Handling

Handle Optimism-specific errors:

```typescript
// @noErrorValidation
import { USwapError } from "@tcswap/sdk";

try {
  await uSwap.transfer({
    /* ... */
  });
} catch (error) {
  if (error instanceof USwapError) {
    switch (error.message.split(":")[0]) {
      case "toolbox_evm_error_estimating_gas_limit":
        console.error("Gas estimation failed - check ETH balance for gas");
        break;
      case "toolbox_evm_gas_estimation_error":
        console.error("Could not fetch gas prices, try again");
        break;
      case "toolbox_evm_error_sending_transaction":
        console.error("Transaction failed:", error.cause);
        break;
      case "core_wallet_connection_not_found":
        console.error("Wallet is not connected for this chain");
        break;
      default:
        console.error("Unknown error:", error);
    }
  }
}
```

## API Reference Summary

### Core Methods (Same as Ethereum)

- `getBalance()` - Get ETH and token balances (`AssetValue[]`)
- `transfer()` - Send ETH or tokens
- `createTransaction()` - Construct transaction parameters
- `sendTransaction()` - Sign and broadcast a transaction object
- `call()` - Execute smart contract functions
- `estimateCall()` - Estimate gas for contract calls

### Gas Management

- `estimateGasPrices()` - Get current gas prices per fee option
- `estimateGasLimit()` - Estimate gas limit for a transfer
- `estimateTransactionFee()` - Estimate the total fee for a transaction

### Optimism Specific

- `getL1GasPrice()` - Get the current L1 base fee from the gas price oracle
- `estimateL1Gas()` - Estimate L1 data gas for a transaction
- `estimateL1GasCost()` - Estimate the L1 data fee for a transaction
