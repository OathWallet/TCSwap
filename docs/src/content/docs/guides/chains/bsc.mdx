This guide covers BNB Smart Chain (BSC) integration with TCSwap, including wallet connections, BEP-20 token transfers, cross-chain swaps, and BSC-specific DeFi protocols.

## Overview

BNB Smart Chain is a fast, low-cost blockchain compatible with Ethereum Virtual Machine. TCSwap provides comprehensive BSC support through:

- **BSC Toolbox**: Fast operations with low BNB gas costs
- **Cross-Chain Bridging**: Seamless transfers between BSC and other networks
- **DEX Integration**: Access to PancakeSwap, Venus, and other BSC protocols
- **BEP-20 Token Support**: Full support for BSC's token standard
- **Multi-Wallet Support**: Compatible with MetaMask, Trust Wallet, and others

## BSC Toolbox

### Wallet Connection

Connect to BSC using Ethereum-compatible wallets:

```typescript
// @noErrorValidation
import { Chain, FeeOption } from "@tcswap/sdk";

await uSwap.connectKeystore(
  [Chain.BinanceSmartChain],
  "your mnemonic phrase"
);

await uSwap.connectEVMWallet([Chain.BinanceSmartChain]);

await uSwap.connectWalletconnect([Chain.BinanceSmartChain]);

await uSwap.connectLedger([Chain.BinanceSmartChain]);
```

### Native BNB Transfers

BNB is the native gas and utility token of BSC:

```typescript
// @noErrorValidation
import { AssetValue } from "@tcswap/sdk";

const txHash = await uSwap.transfer({
  recipient: "0x742c4B4F3e0b5b069F5DCF8A65Eaf8d3E888a3E7",
  assetValue: AssetValue.from({
    chain: Chain.BinanceSmartChain,
    value: "0.1",
  }),
  feeOptionKey: FeeOption.Fast,
});

console.log(`Transaction hash: ${txHash}`);
```

## BSC-Specific Features

### Popular BSC Tokens

```typescript
// @noErrorValidation

const bscTokens = {
  WBNB: "0xbb4CdB9CBd36B01bD1cBaEBF2De08d9173bc095c",
  BUSD: "0xe9e7CEA3DedcA5984780Bafc599bD69ADd087D56",
  USDT: "0x55d398326f99059fF775485246999027B3197955",
  USDC: "0x8AC76a51cc950d9822D68b83fE1Ad97B32Cd580d",
  CAKE: "0x0E09FaBB73Bd3Ade0a17ECC321fD13a19e81cE82",
  XVS: "0xcF6BB5389c92Bdda8a3747Ddb454cB7a64626C63",
  VAI: "0x4BD17003473389A42DAF6a0a729f6Fdb328BbBd7",
  SXP: "0x47BEAd2563dCBf3bF2c9407fEa4dC236fAbA485A",
};

const getBSCPortfolio = async () => {
  const balances = {};
  const address = uSwap.getAddress(Chain.BinanceSmartChain);

  // Returns the native balance plus every token the address holds as AssetValue[]
  const assetValues = await toolbox.getBalance(address);

  for (const [symbol, tokenAddress] of Object.entries(bscTokens)) {
    const balance = assetValues.find(
      (asset) => asset.address?.toLowerCase() === tokenAddress.toLowerCase()
    );
    balances[symbol] = balance?.toSignificant(6) ?? "0";
  }

  return balances;
};
```

## Error Handling

Handle BSC-specific errors:

```typescript
// @noErrorValidation
import { USwapError } from "@tcswap/sdk";

try {
  await uSwap.transfer({
    /* ... */
  });
} catch (error) {
  if (error instanceof USwapError) {
    switch (error.message.split(":")[0]) {
      case "toolbox_evm_error_estimating_gas_limit":
        console.error("Gas estimation failed - check BNB balance for gas");
        break;
      case "toolbox_evm_gas_estimation_error":
        console.error("Could not fetch gas prices, try again");
        break;
      case "toolbox_evm_error_sending_transaction":
        console.error("Transaction failed:", error.cause);
        break;
      case "core_wallet_connection_not_found":
        console.error("Wallet is not connected for this chain");
        break;
      default:
        console.error("Unknown error:", error);
    }
  }
}
```

## API Reference Summary

### Core Methods (Same as Ethereum)

- `getBalance()` - Get BNB and token balances (`AssetValue[]`)
- `transfer()` - Send BNB or tokens
- `createTransaction()` - Construct transaction parameters
- `sendTransaction()` - Sign and broadcast a transaction object
- `call()` - Execute smart contract functions
- `estimateCall()` - Estimate gas for contract calls

### Gas Management

- `estimateGasPrices()` - Get current gas prices per fee option
- `estimateGasLimit()` - Estimate gas limit for a transfer
- `estimateTransactionFee()` - Estimate the total fee for a transaction
