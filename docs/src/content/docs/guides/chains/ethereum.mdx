This guide covers Ethereum integration with TCSwap, including wallet connections, token transfers, cross-chain swaps, and EVM-specific features.

## Overview

Ethereum is the leading smart contract blockchain and the foundation of DeFi. TCSwap provides comprehensive Ethereum support through:

- **Ethereum Toolbox**: Core blockchain operations (transfers, contract calls, gas estimation)
- **EVM Plugin**: Enhanced features for decentralized exchanges and cross-chain operations
- **ERC-20 Support**: Full support for Ethereum's token standard
- **Multi-Wallet Support**: Compatible with MetaMask, WalletConnect, Coinbase Wallet, and hardware wallets
- **Gas Optimization**: EIP-1559 support with dynamic fee estimation

## Getting Started

### Installation

```bash
# Full SDK (recommended)
bun add @tcswap/sdk

# Individual packages for smaller bundles
bun add @tcswap/toolboxes @tcswap/plugins
```

## Ethereum Toolbox

### Wallet Connection

Connect to Ethereum using various wallet types:

```typescript
// @noErrorValidation
import { Chain, FeeOption } from "@tcswap/sdk";

await uSwap.connectKeystore([Chain.Ethereum], "your mnemonic phrase");

await uSwap.connectEVMWallet([Chain.Ethereum]);

await uSwap.connectWalletconnect([Chain.Ethereum]);

await uSwap.connectLedger([Chain.Ethereum]);
```

### Native ETH Transfers

```typescript
// @noErrorValidation
import { AssetValue } from "@tcswap/sdk";

const txHash = await uSwap.transfer({
  recipient: "0x742c4B4F3e0b5b069F5DCF8A65Eaf8d3E888a3E7",
  assetValue: AssetValue.from({
    chain: Chain.Ethereum,
    value: "0.1",
  }),
  feeOptionKey: FeeOption.Fast,
});

console.log(`Transaction hash: ${txHash}`);
```

### ERC-20 Token Transfers

```typescript
// @noErrorValidation

const usdcTransfer = await uSwap.transfer({

const usdcBalance = balances.find(

```

### Token Approvals

ERC-20 tokens require approvals before they can be spent by contracts:

```typescript
// @noErrorValidation
import { getProvider } from "@tcswap/toolboxes/evm";

const isApproved = await toolbox.isApproved({
  assetAddress: "0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48",
  spenderAddress: "0x...",
  from: "0x742c4B4F3e0b5b069F5DCF8A65Eaf8d3E888a3E7",
  amount: 1000000000n,
});

if (!isApproved) {
  const approveTx = await toolbox.approve({
    assetAddress: "0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48",
    spenderAddress: "0x...",
    amount: 1000000000n,
  });

  console.log(`Approval transaction: ${approveTx}`);

  const provider = await getProvider(Chain.Ethereum);
  await provider.waitForTransaction(approveTx);
}

// With a connected wallet, the client can handle approvals as well
const usdc = AssetValue.from({
  asset: "ETH.USDC-0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48",
  value: "1000",
});

if (!(await uSwap.isAssetValueApproved(usdc, "0x..."))) {
  await uSwap.approveAssetValue(usdc, "0x...");
}
```

### Gas Management

Ethereum supports both legacy and EIP-1559 fee structures:

```typescript
// @noErrorValidation

const eip1559Tx = await toolbox.createTransaction({
  recipient: "0x742c4B4F3e0b5b069F5DCF8A65Eaf8d3E888a3E7",
  sender: "0xYourAddress",
  assetValue: AssetValue.from({ chain: Chain.Ethereum, value: "0.1" }),
  maxFeePerGas: 20000000000n,
  maxPriorityFeePerGas: 2000000000n,
});

const legacyTx = await toolbox.createTransaction({
  recipient: "0x742c4B4F3e0b5b069F5DCF8A65Eaf8d3E888a3E7",
  sender: "0xYourAddress",
  assetValue: AssetValue.from({ chain: Chain.Ethereum, value: "0.1" }),
  gasPrice: 20000000000n,
});

const txHash = await toolbox.sendTransaction({ ...eip1559Tx, feeOptionKey: FeeOption.Fast });

const gasPrices = await toolbox.estimateGasPrices();
console.log({
  average: gasPrices.average.maxFeePerGas,
  fast: gasPrices.fast.maxFeePerGas,
  fastest: gasPrices.fastest.maxFeePerGas,
});

const fee = await toolbox.estimateTransactionFee({
  ...eip1559Tx,
  chain: Chain.Ethereum,
  feeOption: FeeOption.Fast,
});
console.log(`Estimated fee: ${fee.toSignificant(6)} ETH`);
```

## Cross-Chain Swaps

Use Ethereum as source or destination for cross-chain swaps via THORChain:

```typescript
// @noErrorValidation
import { USwapApi } from "@tcswap/sdk";

const { routes: ethToBtcRoutes } = await USwapApi.getSwapQuote({
  sellAsset: "ETH.ETH",
  sellAmount: "1",
  buyAsset: "BTC.BTC",
  sourceAddress: uSwap.getAddress(Chain.Ethereum),
  destinationAddress: uSwap.getAddress(Chain.Bitcoin),
});

const swapTx = await uSwap.swap({
  route: ethToBtcRoutes[0],
  feeOptionKey: FeeOption.Fast,
});

const { routes: usdcToRuneRoutes } = await USwapApi.getSwapQuote({
  sellAsset: "ETH.USDC-0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48",
  sellAmount: "1000",
  buyAsset: "THOR.RUNE",
  sourceAddress: uSwap.getAddress(Chain.Ethereum),
  destinationAddress: uSwap.getAddress(Chain.THORChain),
});

const swapResult = await uSwap.swap({
  route: usdcToRuneRoutes[0],
  feeOptionKey: FeeOption.Average,
});
```

## Address Validation

```typescript
// @noErrorValidation
import { evmValidateAddress, toChecksumAddress } from "@tcswap/toolboxes/evm";

const isValidAddress = evmValidateAddress({
  address: "0x742c4B4F3e0b5b069F5DCF8A65Eaf8d3E888a3E7",
});
console.log(isValidAddress);

// Same check through the toolbox
toolbox.validateAddress("0x742c4B4F3e0b5b069F5DCF8A65Eaf8d3E888a3E7");

try {
  const checksumAddress = toChecksumAddress(
    "0x742c4b4f3e0b5b069f5dcf8a65eaf8d3e888a3e7"
  );
  console.log(checksumAddress);
} catch (error) {
  console.error("Invalid address");
}
```

## Fee Rate Configuration

Configure gas fees based on network conditions:

```typescript
// @noErrorValidation
import { FeeOption, USwapConfig } from "@tcswap/sdk";

// Multipliers applied to the base gas price for each fee option
USwapConfig.setFeeMultipliers({
  [FeeOption.Average]: 1.0,
  [FeeOption.Fast]: 1.5,
  [FeeOption.Fastest]: 2.0,
});

const customTx = await uSwap.transfer({
  recipient: "0x742c4B4F3e0b5b069F5DCF8A65Eaf8d3E888a3E7",
  assetValue: AssetValue.from({ chain: Chain.Ethereum, value: "0.1" }),
  feeOptionKey: FeeOption.Fastest,
});
```

## Error Handling

Handle Ethereum-specific errors appropriately:

```typescript
// @noErrorValidation
import { USwapError } from "@tcswap/sdk";

try {
  await uSwap.transfer({
    /* ... */
  });
} catch (error) {
  if (error instanceof USwapError) {
    switch (error.message.split(":")[0]) {
      case "toolbox_evm_no_signer":
        console.error("No signer available for this wallet");
        break;
      case "toolbox_evm_error_estimating_gas_limit":
        console.error("Could not estimate gas");
        break;
      case "toolbox_evm_error_sending_transaction":
        console.error("Transaction failed:", error.cause);
        break;
      case "toolbox_evm_no_contract_address":
        console.error("Token contract address could not be resolved");
        break;
      case "core_wallet_connection_not_found":
        console.error("Ethereum wallet is not connected");
        break;
      default:
        console.error("Unknown error:", error);
    }
  }
}
```

### Transaction Monitoring

The toolbox returns transaction hashes; use an ethers provider to track them:

```typescript
// @noErrorValidation
import { getProvider } from "@tcswap/toolboxes/evm";

const txHash = await uSwap.transfer({
  /* ... */
});

const provider = await getProvider(Chain.Ethereum);

const receipt = await provider.waitForTransaction(txHash);
console.log(`Confirmed in block ${receipt?.blockNumber}`);

const txDetails = await provider.getTransactionReceipt(txHash);
console.log({
  blockNumber: txDetails?.blockNumber,
  gasUsed: txDetails?.gasUsed,
  status: txDetails?.status,
});
```

## Best Practices

1. **Always validate addresses** before sending transactions:

   ```typescript
   import { evmValidateAddress } from "@tcswap/toolboxes/evm";

   if (!evmValidateAddress({ address: recipient })) {
     throw new Error("Invalid Ethereum address");
   }
   ```

2. **Check balances** before transactions:

   ```typescript
   const [ethBalance] = await toolbox.getBalance(senderAddress);
   const requiredAmount = AssetValue.from({
     chain: Chain.Ethereum,
     value: "0.1",
   });

   if (ethBalance.lt(requiredAmount.add(estimatedFee))) {
     throw new Error("Insufficient balance");
   }
   ```

3. **Use appropriate gas limits** for different operations:

   ```typescript
   const gasLimits = {
     ethTransfer: "21000",
     erc20Transfer: "65000",
     contractCall: "100000-500000",
     complexDeFi: "500000+",
   };
   ```

4. **Handle network congestion**:

   ```typescript
   const gasPrices = await toolbox.estimateGasPrices();

   if ((gasPrices.fast.maxFeePerGas ?? 0n) > 50000000000n) {
     console.warn("Network is congested, consider waiting");
   }
   ```

5. **Batch operations** when possible (`ETHToolbox` only):

   ```typescript
   const multicallTx = await toolbox.multicall([
     { address: "0x...", data: "0x..." },
     { address: "0x...", data: "0x..." },
   ]);
   ```

## Troubleshooting

### Common Issues

1. **"Insufficient funds for gas"**

   - Ensure you have enough ETH to cover transaction gas costs
   - Check gas price isn't set too high

2. **"Transaction underpriced"**

   - Increase gas price or use EIP-1559 with higher maxFeePerGas
   - Use FeeOption.Fast or FeeOption.Fastest

3. **"Nonce too low"**

   - Transaction nonce conflicts with pending transaction
   - Wait for previous transactions to confirm

4. **Token transfer fails**
   - Check token approval status
   - Verify token contract address is correct
   - Ensure recipient address can receive tokens

## API Reference Summary

### Core Methods

- `getBalance()` - Get ETH and token balances (`AssetValue[]`)
- `transfer()` - Send ETH or tokens
- `createTransaction()` - Construct transaction parameters
- `sendTransaction()` - Sign and broadcast a transaction object
- `call()` - Execute smart contract functions
- `estimateCall()` - Estimate gas for contract calls

### Token Methods

- `approve()` - Approve token spending
- `isApproved()` - Check approval status
- `approvedAmount()` - Get current allowance

### Utility Methods

- `estimateGasPrices()` - Get current gas prices per fee option
- `estimateTransactionFee()` - Estimate the fee for a transaction
- `validateAddress()` - Validate address format
- `multicall()` - Batch contract calls (`ETHToolbox` only)
