This guide covers Arbitrum One integration with TCSwap, including wallet connections, token transfers, cross-chain swaps, and Layer 2 specific optimizations.

## Overview

Arbitrum One is a leading Ethereum Layer 2 scaling solution that provides faster and cheaper transactions while maintaining Ethereum security. TCSwap provides full Arbitrum support through:

- **Arbitrum Toolbox**: Optimized Layer 2 operations with lower gas costs
- **Cross-Chain Bridging**: Seamless transfers between Ethereum and Arbitrum
- **DEX Integration**: Access to Arbitrum DEXs like Camelot, TraderJoe, and SushiSwap
- **Multi-Wallet Support**: Compatible with all Ethereum wallets
- **Gas Optimization**: Layer 2 gas estimation and fee management

## Arbitrum Toolbox

### Wallet Connection

Connect to Arbitrum using Ethereum-compatible wallets:

```typescript
// @noErrorValidation
import { Chain, FeeOption } from "@tcswap/sdk";

await uSwap.connectKeystore([Chain.Arbitrum], "your mnemonic phrase");

await uSwap.connectEVMWallet([Chain.Arbitrum]);

await uSwap.connectWalletconnect([Chain.Arbitrum]);

await uSwap.connectLedger([Chain.Arbitrum]);
```

### Native ETH Transfers

ETH on Arbitrum is the same as Ethereum ETH, just on Layer 2:

```typescript
// @noErrorValidation
import { AssetValue } from "@tcswap/sdk";

const txHash = await uSwap.transfer({
  recipient: "0x742c4B4F3e0b5b069F5DCF8A65Eaf8d3E888a3E7",
  assetValue: AssetValue.from({
    chain: Chain.Arbitrum,
    value: "0.1",
  }),
  feeOptionKey: FeeOption.Fast,
});

console.log(`Transaction hash: ${txHash}`);
```

### Layer 2 Optimizations

```typescript
// @noErrorValidation
import { getProvider } from "@tcswap/toolboxes/evm";

const batchOperations = async () => {
  const sender = uSwap.getAddress(Chain.Arbitrum);
  const provider = await getProvider(Chain.Arbitrum);
  const nonce = await provider.getTransactionCount(sender);

  const tx1 = await toolbox.createTransaction({
    recipient: "0x...",
    sender,
    assetValue: AssetValue.from({ chain: Chain.Arbitrum, value: "0.1" }),
    nonce,
  });

  const tx2 = await toolbox.createTransaction({
    recipient: "0x...",
    sender,
    assetValue: AssetValue.from({ chain: Chain.Arbitrum, value: "0.1" }),
    nonce: nonce + 1,
  });

  const [hash1, hash2] = await Promise.all([
    toolbox.sendTransaction(tx1),
    toolbox.sendTransaction(tx2),
  ]);

  return [hash1, hash2];
};
```

## Error Handling

Handle Arbitrum-specific errors:

```typescript
// @noErrorValidation
import { USwapError } from "@tcswap/sdk";

try {
  await uSwap.transfer({
    /* ... */
  });
} catch (error) {
  if (error instanceof USwapError) {
    switch (error.message.split(":")[0]) {
      case "toolbox_evm_error_estimating_gas_limit":
        console.error("Gas estimation failed - check ETH balance for gas on Arbitrum");
        break;
      case "toolbox_evm_gas_estimation_error":
        console.error("Could not fetch gas prices - may be network congestion");
        break;
      case "toolbox_evm_error_sending_transaction":
        console.error("Transaction failed:", error.cause);
        break;
      default:
        console.error("Unknown error:", error);
    }
  }
}
```

## API Reference Summary

### Core Methods (Same as Ethereum)

- `getBalance()` - Get ETH and token balances (`AssetValue[]`)
- `transfer()` - Send ETH or tokens
- `createTransaction()` - Construct transaction parameters
- `sendTransaction()` - Sign and broadcast a transaction object
- `call()` - Execute smart contract functions
- `estimateCall()` - Estimate gas for contract calls

### Gas Management

- `estimateGasPrices()` - Get current L2 gas prices per fee option
- `estimateGasLimit()` - Estimate gas limit for a transfer
- `estimateTransactionFee()` - Estimate the total fee for a transaction
