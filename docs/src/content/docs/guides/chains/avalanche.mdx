This guide covers Avalanche C-Chain integration with TCSwap, including wallet connections, token transfers, cross-chain swaps, and Avalanche-specific DeFi protocols.

## Overview

Avalanche is a high-performance blockchain platform with sub-second finality and low transaction costs. TCSwap provides comprehensive Avalanche support through:

- **Avalanche Toolbox**: Fast, low-cost operations on C-Chain
- **Cross-Chain Bridging**: Seamless transfers between different networks
- **DEX Integration**: Access to TraderJoe, Pangolin, and other native DEXs
- **Multi-Wallet Support**: Compatible with MetaMask and other Ethereum wallets
- **Native Token Support**: Full AVAX and ERC-20 token operations

## Avalanche Toolbox

### Wallet Connection

Connect to Avalanche using Ethereum-compatible wallets:

```typescript
// @noErrorValidation
import { Chain, FeeOption } from "@tcswap/sdk";

await uSwap.connectKeystore([Chain.Avalanche], "your mnemonic phrase");

await uSwap.connectEVMWallet([Chain.Avalanche]);

await uSwap.connectWalletconnect([Chain.Avalanche]);

await uSwap.connectLedger([Chain.Avalanche]);
```

### Native AVAX Transfers

AVAX is the native gas and utility token of Avalanche:

```typescript
// @noErrorValidation
import { AssetValue } from "@tcswap/sdk";

const txHash = await uSwap.transfer({
  recipient: "0x742c4B4F3e0b5b069F5DCF8A65Eaf8d3E888a3E7",
  assetValue: AssetValue.from({
    chain: Chain.Avalanche,
    value: "1",
  }),
  feeOptionKey: FeeOption.Fast,
});

console.log(`Transaction hash: ${txHash}`);
```

## Avalanche-Specific Features

### Native Token Operations

```typescript
// @noErrorValidation

const avalancheTokens = {
  WAVAX: "0xB31f66AA3C1e785363F0875A1B74E27b85FD66c7",
  USDC: "0xB97EF9Ef8734C71904D8002F8b6Bc66Dd9c48a6E",
  USDt: "0x9702230A8Ea53601f5cD2dc00fDBc13d4dF4A8c7",
  JOE: "0x6e84a6216eA6dACC71eE8E6b0a5B7322EEbC0fDd",
  PNG: "0x60781C2586D68229fde47564546784ab3fACA982",
  QI: "0x8729438EB15e2C8B576fCc6AeCdA6A148776C0F5",
};

const getPortfolioBalances = async () => {
  const balances = {};
  const address = uSwap.getAddress(Chain.Avalanche);

  // Returns AVAX plus every token the address holds as AssetValue[]
  const assetValues = await toolbox.getBalance(address);

  for (const [symbol, tokenAddress] of Object.entries(avalancheTokens)) {
    const balance = assetValues.find(
      (asset) => asset.address?.toLowerCase() === tokenAddress.toLowerCase()
    );
    balances[symbol] = balance?.toSignificant(6) ?? "0";
  }

  return balances;
};
```

## Error Handling

Handle Avalanche-specific errors:

```typescript
// @noErrorValidation
import { USwapError } from "@tcswap/sdk";

try {
  await uSwap.transfer({
    /* ... */
  });
} catch (error) {
  if (error instanceof USwapError) {
    switch (error.message.split(":")[0]) {
      case "toolbox_evm_error_estimating_gas_limit":
        console.error("Gas estimation failed - check AVAX balance for gas");
        break;
      case "toolbox_evm_gas_estimation_error":
        console.error("Could not fetch gas prices, try again");
        break;
      case "toolbox_evm_error_sending_transaction":
        console.error("Transaction failed:", error.cause);
        break;
      case "core_wallet_connection_not_found":
        console.error("Avalanche wallet is not connected");
        break;
      default:
        console.error("Unknown error:", error);
    }
  }
}
```

## Performance Optimization

### Transaction Batching

```typescript
// @noErrorValidation

const batchOperations = async () => {
  const operations = [];

  for (let i = 0; i < 5; i++) {
    const tx = toolbox.transfer({
      recipient: `0x742c4B4F3e0b5b069F5DCF8A65Eaf8d3E888a3E${i}`,
      assetValue: AssetValue.from({ chain: Chain.Avalanche, value: "0.1" }),
```

## API Reference Summary

### Core Methods (Same as Ethereum)

- `getBalance()` - Get AVAX and token balances (`AssetValue[]`)
- `transfer()` - Send AVAX or tokens
- `createTransaction()` - Construct transaction parameters
- `sendTransaction()` - Sign and broadcast a transaction object
- `call()` - Execute smart contract functions
- `estimateCall()` - Estimate gas for contract calls

### Gas Management

- `estimateGasPrices()` - Get current gas prices per fee option
- `estimateGasLimit()` - Estimate gas limit for a transfer
- `estimateTransactionFee()` - Estimate the total fee for a transaction
