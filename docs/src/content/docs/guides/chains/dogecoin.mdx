This guide covers Dogecoin integration with TCSwap, including wallet connections, UTXO management, fast block times, and cross-chain swaps.

## Overview

Dogecoin is a fun, friendly cryptocurrency originally created as a joke but has become widely adopted for tipping and micropayments. TCSwap provides comprehensive Dogecoin support through:

- **UTXO Toolbox**: UTXO selection, PSBT construction and signing for Dogecoin
- **Fast Block Times**: ~1 minute block confirmations
- **Very Low Fees**: Optimized for micropayments and tipping
- **Cross-Chain Swaps**: Seamless swaps with other cryptocurrencies via THORChain
- **Multi-Wallet Support**: Compatible with hardware and software wallets

## Dogecoin Toolbox

### Wallet Connection

Connect to Dogecoin using various wallet types:

```typescript
// @noErrorValidation
import { Chain, FeeOption } from "@tcswap/sdk";

await uSwap.connectKeystore([Chain.Dogecoin], "your mnemonic phrase");

await uSwap.connectLedger([Chain.Dogecoin]);

await uSwap.connectTrezor([Chain.Dogecoin], [44, 3, 0, 0, 0]);

await uSwap.connectKeepkey([Chain.Dogecoin]);
```

### Addresses

Dogecoin uses legacy P2PKH addresses (`D...`):

```typescript
// @noErrorValidation

const dogeAddress = uSwap.getAddress(Chain.Dogecoin);

console.log("Dogecoin address:", dogeAddress);
console.log("Valid DOGE address:", dogeToolbox.validateAddress(dogeAddress));
```

### Dogecoin Transfers

```typescript
// @noErrorValidation
import { AssetValue } from "@tcswap/sdk";

const txHash = await uSwap.transfer({
  recipient: "DH5yaieqoZN36fDVciNyRueRGvGLR3mr7L",
  assetValue: AssetValue.from({
    chain: Chain.Dogecoin,
    value: "100",
  }),
  feeOptionKey: FeeOption.Fast,
});

console.log(`Dogecoin transaction hash: ${txHash}`);

const tip = await dogeToolbox.transfer({
  recipient: "DH5yaieqoZN36fDVciNyRueRGvGLR3mr7L",
  assetValue: AssetValue.from({ chain: Chain.Dogecoin, value: "1" }),
  feeOptionKey: FeeOption.Average,
  memo: "Great meme!",
});

console.log("Much wow! Tip sent:", tip);

const batchTips = async () => {
  const recipients = [
    { address: "DH5yaieqoZN36fDVciNyRueRGvGLR3mr7L", amount: "5" },
    { address: "DFundmtrigzA6E25Swr2pRe4Eb79bGP8G1", amount: "10" },
    { address: "DAecAe6RkjvqmzrCLKJeH4fLHMdQ3wKtSC", amount: "2" },
  ];

  for (const { address, amount } of recipients) {
    const tx = await dogeToolbox.transfer({
      recipient: address,
      assetValue: AssetValue.from({ chain: Chain.Dogecoin, value: amount }),
      feeOptionKey: FeeOption.Average,
    });
    console.log(`Tipped ${amount} DOGE to ${address}: ${tx}`);
  }
};
```

### UTXO Management

UTXO selection happens automatically in `transfer()`; use `createTransaction()` to build an unsigned PSBT yourself:

```typescript
// @noErrorValidation
import { getUtxoApi } from "@tcswap/toolboxes/utxo";

const sender = await dogeToolbox.getAddress();

const utxos = await getUtxoApi(Chain.Dogecoin).getUtxos({ address: sender });

utxos.forEach((utxo, index) => {
  console.log(`UTXO ${index}: ${utxo.value} koinu (${utxo.hash}:${utxo.index})`);
});

const feeRates = await dogeToolbox.getFeeRates();

const { psbt, inputs } = await dogeToolbox.createTransaction({
  sender,
  recipient: "DH5yaieqoZN36fDVciNyRueRGvGLR3mr7L",
  assetValue: AssetValue.from({ chain: Chain.Dogecoin, value: "50" }),
  feeRate: feeRates[FeeOption.Average],
});

console.log(`Selected ${inputs.length} inputs`);
```


## Cross-Chain Swaps

Dogecoin is supported in THORChain cross-chain swaps:

```typescript
// @noErrorValidation
import { USwapApi } from "@tcswap/sdk";

const { routes } = await USwapApi.getSwapQuote({
  sellAsset: "DOGE.DOGE",
  sellAmount: "10000",
  buyAsset: "BTC.BTC",
  sourceAddress: uSwap.getAddress(Chain.Dogecoin),
  destinationAddress: uSwap.getAddress(Chain.Bitcoin),
});

const [bestRoute] = routes;

console.log("DOGE -> BTC quote:", {
  expectedOutput: bestRoute.expectedBuyAmount,
  fees: bestRoute.fees,
  estimatedTime: bestRoute.estimatedTime,
});

const swapTx = await uSwap.swap({
  route: bestRoute,
  feeOptionKey: FeeOption.Fast,
});

const dogeToUsdcQuote = await USwapApi.getSwapQuote({
  sellAsset: "DOGE.DOGE",
  sellAmount: "5000",
  buyAsset: "ETH.USDC-0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48",
  sourceAddress: uSwap.getAddress(Chain.Dogecoin),
  destinationAddress: uSwap.getAddress(Chain.Ethereum),
});

const dogeToRuneQuote = await USwapApi.getSwapQuote({
  sellAsset: "DOGE.DOGE",
  sellAmount: "1000",
  buyAsset: "THOR.RUNE",
  sourceAddress: uSwap.getAddress(Chain.Dogecoin),
  destinationAddress: uSwap.getAddress(Chain.THORChain),
});
```

## Network Configuration

### UTXO Data Provider

Dogecoin balances, UTXOs and fee rates come from Blockchair. Set an API key to avoid rate limits; `blockchairApiUrl` in `envs` can point the requests at your own proxy:

```typescript
// @noErrorValidation
import { USwapConfig } from "@tcswap/sdk";

USwapConfig.setApiKey("blockchair", "your-blockchair-api-key");
```

## Error Handling

Handle Dogecoin-specific errors:

```typescript
// @noErrorValidation
import { USwapError } from "@tcswap/sdk";

try {
  await uSwap.transfer({
    /* ... */
  });
} catch (error) {
  if (error instanceof USwapError) {
    const errorKey = error.message.split(":")[0];

    switch (errorKey) {
      case "toolbox_utxo_insufficient_balance":
        console.error("Such insufficient! Much need more DOGE!");
        break;
      case "toolbox_utxo_invalid_address":
        console.error("Invalid Dogecoin address format");
        break;
      case "toolbox_utxo_broadcast_failed":
        console.error("Broadcast failed:", error.cause);
        break;
      case "toolbox_utxo_api_error":
        console.error("UTXO data provider error:", error.cause);
        break;
      default:
        console.error("Unknown Dogecoin error:", error);
    }
  }
}
```

## Best Practices

1. **Use for Micropayments**:

   ```typescript
   const micropayment = async (recipient: string, amount: number) => {
     return await dogeToolbox.transfer({
       recipient,
       assetValue: AssetValue.from({
         chain: Chain.Dogecoin,
         value: amount.toString(),
       }),
       feeOptionKey: FeeOption.Average,
     });
   };
   ```

2. **Check the Max Sendable Amount** before large payouts:

   ```typescript
   const maxSendable = await dogeToolbox.estimateMaxSendableAmount({
     from: await dogeToolbox.getAddress(),
   });

   console.log(`Can send up to ${maxSendable.getValue("string")} DOGE`);
   ```

3. **Validate Addresses** before sending:

   ```typescript
   if (!dogeToolbox.validateAddress(recipient)) {
     throw new Error("Invalid Dogecoin address");
   }
   ```

## Troubleshooting

### Common Issues

1. **Dust outputs**: the UTXO toolbox uses a dust threshold of 100,000 koinu (0.001 DOGE) for Dogecoin during coin selection. Keep payment amounts well above it.

2. **Rate limits on balance/UTXO lookups**: set a Blockchair API key with `USwapConfig.setApiKey("blockchair", ...)`.

## API Reference Summary

### Core Methods

- `getBalance(address)` - Get balances as `AssetValue[]`
- `transfer()` - Send DOGE with automatic UTXO selection
- `createTransaction()` - Build an unsigned PSBT with selected inputs
- `broadcastTx(txHex)` - Broadcast a signed raw transaction

### Fee Management

- `getFeeRates()` - Get current fee rates per `FeeOption`
- `estimateTransactionFee()` - Estimate fee for a transaction
- `estimateMaxSendableAmount()` - Balance minus estimated fee
- `calculateTxSize()` - Estimate transaction size in bytes

### Address and Key Methods

- `getAddress()` - Address of the configured signer (D...)
- `validateAddress(address)` - Validate DOGE address format
- `createKeysForPath()` / `getAddressFromKeys()` - Derive keys and addresses
- `getPrivateKeyFromMnemonic()` - Export a WIF private key
