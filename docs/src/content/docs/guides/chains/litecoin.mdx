This guide covers Litecoin integration with TCSwap, including wallet connections, UTXO management, fast confirmations, and cross-chain swaps.

## Overview

Litecoin is a peer-to-peer cryptocurrency based on Bitcoin with faster block times and lower fees. TCSwap provides comprehensive Litecoin support through:

- **UTXO Toolbox**: UTXO selection, PSBT construction and signing for Litecoin
- **Fast Block Times**: ~2.5 minute block confirmations vs Bitcoin's ~10 minutes
- **Cross-Chain Swaps**: Seamless swaps with other cryptocurrencies via THORChain
- **SegWit Support**: Native SegWit (`ltc1...`) addresses for lower transaction fees
- **Multi-Wallet Support**: Compatible with hardware and software wallets

## Litecoin Toolbox

### Wallet Connection

Connect to Litecoin using various wallet types:

```typescript
// @noErrorValidation
import { Chain, FeeOption } from "@tcswap/sdk";

await uSwap.connectKeystore([Chain.Litecoin], "your mnemonic phrase");

await uSwap.connectLedger([Chain.Litecoin]);

await uSwap.connectTrezor([Chain.Litecoin], [84, 2, 0, 0, 0]);

await uSwap.connectKeepkey([Chain.Litecoin]);
```

### Addresses

The keystore and toolbox derive a Native SegWit (`ltc1...`) address:

```typescript
// @noErrorValidation

const address = uSwap.getAddress(Chain.Litecoin);

const toolboxAddress = await ltcToolbox.getAddress();

console.log("Litecoin address:", address);
```

### Litecoin Transfers

```typescript
// @noErrorValidation
import { AssetValue } from "@tcswap/sdk";

const txHash = await uSwap.transfer({
  recipient: "ltc1qxy2kgdygjrsqtzq2n0yrf2493p83kkfjhx0wlh",
  assetValue: AssetValue.from({
    chain: Chain.Litecoin,
    value: "0.1",
  }),
  feeOptionKey: FeeOption.Fast,
});

console.log(`Litecoin transaction hash: ${txHash}`);

// Explicit fee rate in sats/vbyte
const customFeeTx = await ltcToolbox.transfer({
  recipient: "LdP8Qox1VAhCzLJNqrr74YovaWYyNBUWvL",
  assetValue: AssetValue.from({ chain: Chain.Litecoin, value: "0.05" }),
  feeRate: 10,
});
```

### UTXO Management

UTXO selection happens automatically in `transfer()`; use `createTransaction()` to build an unsigned PSBT yourself:

```typescript
// @noErrorValidation
import { getUtxoApi } from "@tcswap/toolboxes/utxo";

const sender = await ltcToolbox.getAddress();

const utxos = await getUtxoApi(Chain.Litecoin).getUtxos({ address: sender });

utxos.forEach((utxo, index) => {
  console.log(`UTXO ${index}: ${utxo.value} litoshis (${utxo.hash}:${utxo.index})`);
});

const { psbt, inputs } = await ltcToolbox.createTransaction({
  sender,
  recipient: "ltc1qxy2kgdygjrsqtzq2n0yrf2493p83kkfjhx0wlh",
  assetValue: AssetValue.from({ chain: Chain.Litecoin, value: "0.1" }),
  feeRate: 10,
});

console.log(`Selected ${inputs.length} inputs`);
```

### Fee Management

```typescript
// @noErrorValidation

const feeRates = await ltcToolbox.getFeeRates();
console.log({
  average: feeRates[FeeOption.Average],
  fast: feeRates[FeeOption.Fast],
  fastest: feeRates[FeeOption.Fastest],
});

const sender = await ltcToolbox.getAddress();

const fee = await ltcToolbox.estimateTransactionFee({
  sender,
  recipient: "ltc1qxy2kgdygjrsqtzq2n0yrf2493p83kkfjhx0wlh",
  assetValue: AssetValue.from({ chain: Chain.Litecoin, value: "0.5" }),
  feeOptionKey: FeeOption.Fast,
});

console.log(`Estimated fee: ${fee.getValue("string")} LTC`);

const maxSendable = await ltcToolbox.estimateMaxSendableAmount({
  from: sender,
  feeOptionKey: FeeOption.Fast,
});
```

## Cross-Chain Swaps

Litecoin is supported in THORChain cross-chain swaps:

```typescript
// @noErrorValidation
import { USwapApi } from "@tcswap/sdk";

const { routes } = await USwapApi.getSwapQuote({
  sellAsset: "LTC.LTC",
  sellAmount: "10",
  buyAsset: "BTC.BTC",
  sourceAddress: uSwap.getAddress(Chain.Litecoin),
  destinationAddress: uSwap.getAddress(Chain.Bitcoin),
});

const [bestRoute] = routes;

console.log("LTC -> BTC quote:", {
  expectedOutput: bestRoute.expectedBuyAmount,
  fees: bestRoute.fees,
  estimatedTime: bestRoute.estimatedTime,
});

const swapTx = await uSwap.swap({
  route: bestRoute,
  feeOptionKey: FeeOption.Fast,
});

const ltcToUsdcQuote = await USwapApi.getSwapQuote({
  sellAsset: "LTC.LTC",
  sellAmount: "5",
  buyAsset: "ETH.USDC-0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48",
  sourceAddress: uSwap.getAddress(Chain.Litecoin),
  destinationAddress: uSwap.getAddress(Chain.Ethereum),
});

const ltcToRuneQuote = await USwapApi.getSwapQuote({
  sellAsset: "LTC.LTC",
  sellAmount: "1",
  buyAsset: "THOR.RUNE",
  sourceAddress: uSwap.getAddress(Chain.Litecoin),
  destinationAddress: uSwap.getAddress(Chain.THORChain),
});
```

## Network Configuration

### UTXO Data Provider

Litecoin balances, UTXOs and fee rates come from Blockchair (with public fallbacks). Set an API key to avoid rate limits; `blockchairApiUrl` in `envs` can point the requests at your own proxy:

```typescript
// @noErrorValidation
import { USwapConfig } from "@tcswap/sdk";

USwapConfig.setApiKey("blockchair", "your-blockchair-api-key");
```

## Error Handling

Handle Litecoin-specific errors:

```typescript
// @noErrorValidation
import { USwapError } from "@tcswap/sdk";

try {
  await uSwap.transfer({
    /* ... */
  });
} catch (error) {
  if (error instanceof USwapError) {
    const errorKey = error.message.split(":")[0];

    switch (errorKey) {
      case "toolbox_utxo_insufficient_balance":
        console.error("Insufficient Litecoin balance");
        break;
      case "toolbox_utxo_invalid_address":
        console.error("Invalid Litecoin address format");
        break;
      case "toolbox_utxo_broadcast_failed":
        console.error("Broadcast failed:", error.cause);
        break;
      case "toolbox_utxo_api_error":
        console.error("UTXO data provider error:", error.cause);
        break;
      default:
        console.error("Unknown Litecoin error:", error);
    }
  }
}
```

## Address Validation

```typescript
// @noErrorValidation
import { Chain, getAddressValidator } from "@tcswap/sdk";

const validateAddress = await getAddressValidator();

const addresses = [
  "ltc1qxy2kgdygjrsqtzq2n0yrf2493p83kkfjhx0wlh",
  "MQMcJhpWHYVeQArcZR3sBgyPZxxRtnH441",
  "LdP8Qox1VAhCzLJNqrr74YovaWYyNBUWvL",
];

addresses.forEach((address) => {
  const isValid = validateAddress({ address, chain: Chain.Litecoin });
  console.log(`${address}: ${isValid ? "Valid" : "Invalid"}`);
});

// Or directly on the toolbox
ltcToolbox.validateAddress("ltc1qxy2kgdygjrsqtzq2n0yrf2493p83kkfjhx0wlh");
```

## Troubleshooting

### Common Issues

1. **Address format confusion with Bitcoin**: Litecoin addresses start with `ltc1`, `L` or `M`. Validation is chain-specific, so a Bitcoin `bc1...` address fails `validateAddress({ address, chain: Chain.Litecoin })`.

2. **Insufficient funds for fee**:

   ```typescript
   const maxSendable = await ltcToolbox.estimateMaxSendableAmount({
     from: await ltcToolbox.getAddress(),
     feeOptionKey: FeeOption.Fast,
   });

   if (maxSendable.lt(AssetValue.from({ chain: Chain.Litecoin, value: "1" }))) {
     console.error("Insufficient funds to cover amount plus fee");
   }
   ```

## API Reference Summary

### Core Methods

- `getBalance(address)` - Get balances as `AssetValue[]`
- `transfer()` - Send LTC with automatic UTXO selection
- `createTransaction()` - Build an unsigned PSBT with selected inputs
- `broadcastTx(txHex)` - Broadcast a signed raw transaction

### Fee Management

- `getFeeRates()` - Get current fee rates per `FeeOption`
- `estimateTransactionFee()` - Estimate fee for a transaction
- `estimateMaxSendableAmount()` - Balance minus estimated fee
- `calculateTxSize()` - Estimate transaction size in vbytes

### Address and Key Methods

- `getAddress()` - Address of the configured signer
- `validateAddress(address)` - Validate Litecoin address format
- `createKeysForPath()` / `getAddressFromKeys()` - Derive keys and addresses
- `getPrivateKeyFromMnemonic()` - Export a WIF private key
