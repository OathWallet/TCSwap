This guide covers Polygon integration with TCSwap, including wallet connections, token transfers, cross-chain swaps, and Polygon-specific DeFi protocols.

## Overview

Polygon is a leading Ethereum Layer 2 scaling solution providing fast, low-cost transactions. TCSwap provides comprehensive Polygon support through:

- **Polygon Toolbox**: Fast operations with minimal MATIC gas costs
- **Cross-Chain Bridging**: Seamless transfers between Ethereum and Polygon
- **DEX Integration**: Access to QuickSwap, SushiSwap, and other Polygon DEXs
- **ERC-20 Compatibility**: Full support for Polygon's token ecosystem
- **Multi-Wallet Support**: Compatible with MetaMask and other Ethereum wallets

## Polygon Toolbox

### Wallet Connection

Connect to Polygon using Ethereum-compatible wallets:

```typescript
// @noErrorValidation
import { Chain, FeeOption } from "@tcswap/sdk";

await uSwap.connectKeystore([Chain.Polygon], "your mnemonic phrase");

await uSwap.connectEVMWallet([Chain.Polygon]);

await uSwap.connectWalletconnect([Chain.Polygon]);

await uSwap.connectLedger([Chain.Polygon]);
```

### Native MATIC Transfers

MATIC is the native gas and utility token of Polygon:

```typescript
// @noErrorValidation
import { AssetValue } from "@tcswap/sdk";

const txHash = await uSwap.transfer({
  recipient: "0x742c4B4F3e0b5b069F5DCF8A65Eaf8d3E888a3E7",
  assetValue: AssetValue.from({
    chain: Chain.Polygon,
    value: "1",
  }),
  feeOptionKey: FeeOption.Fast,
});

console.log(`Transaction hash: ${txHash}`);
```

```typescript
const polygonTokens = {
  WMATIC: "0x0d500B1d8E8eF31E21C99d1Db9A6444d3ADf1270",
  USDC: "0x2791Bca1f2de4661ED88A30C99A7a9449Aa84174",

  SUSHI: "0x0b3F868E0BE5597D5DB7fEB59E1CADBb0fdDa50a",
};

const getPolygonPortfolio = async () => {
  const balances = {};
  const address = uSwap.getAddress(Chain.Polygon);

  // Returns the native balance plus every token the address holds as AssetValue[]
  const assetValues = await toolbox.getBalance(address);

  for (const [symbol, tokenAddress] of Object.entries(polygonTokens)) {
    const balance = assetValues.find(
      (asset) => asset.address?.toLowerCase() === tokenAddress.toLowerCase()
    );
    balances[symbol] = balance?.toSignificant(6) ?? "0";
  }

  return balances;
};
```

## Error Handling

Handle Polygon-specific errors:

```typescript
// @noErrorValidation
import { USwapError } from "@tcswap/sdk";

try {
  await uSwap.transfer({
    /* ... */
  });
} catch (error) {
  if (error instanceof USwapError) {
    switch (error.message.split(":")[0]) {
      case "toolbox_evm_error_estimating_gas_limit":
        console.error("Gas estimation failed - check POL balance for gas");
        break;
      case "toolbox_evm_gas_estimation_error":
        console.error("Could not fetch gas prices, try again");
        break;
      case "toolbox_evm_error_sending_transaction":
        console.error("Transaction failed:", error.cause);
        break;
      case "core_wallet_connection_not_found":
        console.error("Wallet is not connected for this chain");
        break;
      default:
        console.error("Unknown error:", error);
    }
  }
}
```

```typescript
const batchOperations = async () => {
```

## API Reference Summary

### Core Methods (Same as Ethereum)

- `getBalance()` - Get POL and token balances (`AssetValue[]`)
- `transfer()` - Send POL or tokens
- `createTransaction()` - Construct transaction parameters
- `sendTransaction()` - Sign and broadcast a transaction object
- `call()` - Execute smart contract functions
- `estimateCall()` - Estimate gas for contract calls

### Gas Management

- `estimateGasPrices()` - Get current gas prices per fee option
- `estimateGasLimit()` - Estimate gas limit for a transfer
- `estimateTransactionFee()` - Estimate the total fee for a transaction
