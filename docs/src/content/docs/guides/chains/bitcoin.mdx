This guide covers Bitcoin integration with TCSwap, including wallet connections, UTXO management, cross-chain swaps, and Bitcoin-specific operations.

## Overview

Bitcoin is the first and most valuable cryptocurrency, using a UTXO (Unspent Transaction Output) model. TCSwap provides comprehensive Bitcoin support through:

- **UTXO Toolbox**: UTXO selection, PSBT construction and signing
- **Cross-Chain Swaps**: Seamless swaps with other cryptocurrencies via THORChain
- **Multi-Wallet Support**: Compatible with hardware wallets and software wallets
- **Fee Optimization**: Dynamic fee estimation based on network conditions
- **Address Formats**: Native SegWit (`bc1q...`) derivation by default, with sending to Legacy, P2SH and bech32 addresses

## Bitcoin Toolbox

### Wallet Connection

Connect to Bitcoin using various wallet types:

```typescript
// @noErrorValidation
import { Chain, FeeOption } from "@tcswap/sdk";

await uSwap.connectKeystore([Chain.Bitcoin], "your mnemonic phrase");

await uSwap.connectLedger([Chain.Bitcoin]);

await uSwap.connectTrezor([Chain.Bitcoin], [84, 0, 0, 0, 0]);

await uSwap.connectKeepkey([Chain.Bitcoin]);
```

### Addresses

The keystore and toolbox derive a Native SegWit address from the configured derivation path:

```typescript
// @noErrorValidation

const address = uSwap.getAddress(Chain.Bitcoin);

const toolboxAddress = await btcToolbox.getAddress();

// Derive a different account index
const secondAccount = await getUtxoToolbox(Chain.Bitcoin, {
  phrase: "your mnemonic phrase",
  index: 1,
});
console.log("Second address:", await secondAccount.getAddress());
```

### Bitcoin Transfers

```typescript
// @noErrorValidation
import { AssetValue } from "@tcswap/sdk";

const txHash = await uSwap.transfer({
  recipient: "bc1qxy2kgdygjrsqtzq2n0yrf2493p83kkfjhx0wlh",
  assetValue: AssetValue.from({
    chain: Chain.Bitcoin,
    value: "0.001",
  }),
  feeOptionKey: FeeOption.Fast,
});

console.log(`Bitcoin transaction hash: ${txHash}`);

// Explicit fee rate in sats/vbyte
const customFeeTx = await btcToolbox.transfer({
  recipient: "bc1qxy2kgdygjrsqtzq2n0yrf2493p83kkfjhx0wlh",
  assetValue: AssetValue.from({ chain: Chain.Bitcoin, value: "0.001" }),
  feeRate: 20,
  memo: "optional OP_RETURN memo",
});
```

### UTXO Management

Bitcoin uses UTXOs (Unspent Transaction Outputs) instead of account balances. UTXO selection happens automatically in `transfer()`; use `createTransaction()` to build an unsigned PSBT yourself:

```typescript
// @noErrorValidation
import { getUtxoApi } from "@tcswap/toolboxes/utxo";

const sender = await btcToolbox.getAddress();

const utxos = await getUtxoApi(Chain.Bitcoin).getUtxos({ address: sender });

utxos.forEach((utxo, index) => {
  console.log(`UTXO ${index}: ${utxo.value} sats (${utxo.hash}:${utxo.index})`);
});

const { psbt, inputs } = await btcToolbox.createTransaction({
  sender,
  recipient: "bc1qxy2kgdygjrsqtzq2n0yrf2493p83kkfjhx0wlh",
  assetValue: AssetValue.from({ chain: Chain.Bitcoin, value: "0.001" }),
  feeRate: 15,
});

console.log(`Selected ${inputs.length} inputs`);
console.log("Unsigned PSBT:", psbt.toBase64());
```

### Fee Estimation

Bitcoin fees are dynamic based on network congestion:

```typescript
// @noErrorValidation

const feeRates = await btcToolbox.getFeeRates();
console.log({
  average: feeRates[FeeOption.Average],
  fast: feeRates[FeeOption.Fast],
  fastest: feeRates[FeeOption.Fastest],
});

const sender = await btcToolbox.getAddress();

const feeEstimate = await btcToolbox.estimateTransactionFee({
  sender,
  recipient: "bc1qxy2kgdygjrsqtzq2n0yrf2493p83kkfjhx0wlh",
  assetValue: AssetValue.from({ chain: Chain.Bitcoin, value: "0.01" }),
  feeOptionKey: FeeOption.Fast,
});

console.log(`Estimated fee: ${feeEstimate.getValue("string")} BTC`);

const maxSendable = await btcToolbox.estimateMaxSendableAmount({
  from: sender,
  feeOptionKey: FeeOption.Fast,
});

console.log(`Max sendable: ${maxSendable.getValue("string")} BTC`);
```

## Cross-Chain Swaps

Bitcoin is fully supported in THORChain cross-chain swaps:

```typescript
// @noErrorValidation
import { USwapApi } from "@tcswap/sdk";

const { routes } = await USwapApi.getSwapQuote({
  sellAsset: "BTC.BTC",
  sellAmount: "0.1",
  buyAsset: "ETH.ETH",
  sourceAddress: uSwap.getAddress(Chain.Bitcoin),
  destinationAddress: uSwap.getAddress(Chain.Ethereum),
  slippage: 3,
});

const [bestRoute] = routes;

console.log("BTC -> ETH quote:", {
  expectedOutput: bestRoute.expectedBuyAmount,
  fees: bestRoute.fees,
  estimatedTime: bestRoute.estimatedTime,
});

const swapTx = await uSwap.swap({
  route: bestRoute,
  feeOptionKey: FeeOption.Fast,
});

const btcToUsdcQuote = await USwapApi.getSwapQuote({
  sellAsset: "BTC.BTC",
  sellAmount: "0.05",
  buyAsset: "ETH.USDC-0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48",
  sourceAddress: uSwap.getAddress(Chain.Bitcoin),
  destinationAddress: uSwap.getAddress(Chain.Ethereum),
});

const btcToRuneQuote = await USwapApi.getSwapQuote({
  sellAsset: "BTC.BTC",
  sellAmount: "0.01",
  buyAsset: "THOR.RUNE",
  sourceAddress: uSwap.getAddress(Chain.Bitcoin),
  destinationAddress: uSwap.getAddress(Chain.THORChain),
});
```

## Advanced Bitcoin Features

### Custom Signing Flow

Build the PSBT with the toolbox, sign it with any signer, and broadcast the raw transaction:

```typescript
// @noErrorValidation

const sender = await btcToolbox.getAddress();

const { psbt } = await btcToolbox.createTransaction({
  sender,
  recipient: "bc1qxy2kgdygjrsqtzq2n0yrf2493p83kkfjhx0wlh",
  assetValue: AssetValue.from({ chain: Chain.Bitcoin, value: "0.005" }),
  feeRate: 20,
});

const signedPsbt = await customBitcoinSigner.signTransaction(psbt);
signedPsbt.finalizeAllInputs();

const txHash = await btcToolbox.broadcastTx(signedPsbt.extractTransaction().toHex());
```

### Transaction Size

```typescript
// @noErrorValidation
import { UTXOScriptType } from "@tcswap/toolboxes/utxo";

const sender = await btcToolbox.getAddress();

const txSize = btcToolbox.calculateTxSize({
  inputs: [
    { hash: "", index: 0, value: 50000, type: UTXOScriptType.P2WPKH, address: sender },
    { hash: "", index: 1, value: 50000, type: UTXOScriptType.P2WPKH, address: sender },
  ],
  outputs: [{ address: "bc1qxy2kgdygjrsqtzq2n0yrf2493p83kkfjhx0wlh", value: 80000 }],
  feeRate: 15,
});

console.log(`Estimated tx size: ${txSize} vbytes`);
```

## Network Configuration

### UTXO Data Provider

UTXO chains read balances, UTXOs and fee rates from Blockchair (with public fallbacks for Bitcoin). Set an API key to avoid rate limits; `blockchairApiUrl` in `envs` can point the requests at your own proxy:

```typescript
// @noErrorValidation
import { USwapConfig } from "@tcswap/sdk";

USwapConfig.setApiKey("blockchair", "your-blockchair-api-key");
```

## Error Handling

Handle Bitcoin-specific errors:

```typescript
// @noErrorValidation
import { USwapError } from "@tcswap/sdk";

try {
  await uSwap.transfer({
    /* ... */
  });
} catch (error) {
  if (error instanceof USwapError) {
    const errorKey = error.message.split(":")[0];

    switch (errorKey) {
      case "toolbox_utxo_insufficient_balance":
        console.error("Insufficient Bitcoin balance");
        break;
      case "toolbox_utxo_invalid_address":
        console.error("Invalid Bitcoin address format");
        break;
      case "toolbox_utxo_no_signer":
        console.error("No signer configured for this toolbox");
        break;
      case "toolbox_utxo_broadcast_failed":
        console.error("Broadcast failed:", error.cause);
        break;
      case "toolbox_utxo_api_error":
        console.error("UTXO data provider error:", error.cause);
        break;
      default:
        console.error("Unknown Bitcoin error:", error);
    }
  }
}
```

## Performance Optimization

### Fee Optimization

```typescript
// @noErrorValidation

const optimizeFee = async (urgency: "low" | "medium" | "high") => {
  const feeRates = await btcToolbox.getFeeRates();

  switch (urgency) {
    case "low":
      return feeRates[FeeOption.Average];
    case "medium":
      return feeRates[FeeOption.Fast];
    case "high":
      return feeRates[FeeOption.Fastest];
  }
};

const optimizedTx = await btcToolbox.transfer({
  recipient: "bc1qxy2kgdygjrsqtzq2n0yrf2493p83kkfjhx0wlh",
  assetValue: AssetValue.from({ chain: Chain.Bitcoin, value: "0.05" }),
  feeRate: await optimizeFee("medium"),
});
```

## Best Practices

1. **Use Native SegWit Addresses**:

   ```typescript
   const recipient = "bc1qxy2kgdygjrsqtzq2n0yrf2493p83kkfjhx0wlh";

   const legacy = "1A1zP1eP5QGefi2DMPTfTL5SLmv7DivfNa";
   ```

2. **Monitor Network Congestion**:

   ```typescript
   const feeRates = await btcToolbox.getFeeRates();

   if (feeRates[FeeOption.Fast] > 50) {
     console.warn("Bitcoin network congested, consider waiting");
   }
   ```

3. **Validate Addresses**:

   ```typescript
   if (!btcToolbox.validateAddress(recipient)) {
     throw new Error("Invalid Bitcoin address");
   }
   ```

## Troubleshooting

### Common Issues

1. **Insufficient funds for fee**:

   ```typescript
   const sender = await btcToolbox.getAddress();
   const maxSendable = await btcToolbox.estimateMaxSendableAmount({
     from: sender,
     feeOptionKey: FeeOption.Fast,
   });

   const amount = AssetValue.from({ chain: Chain.Bitcoin, value: "0.01" });

   if (maxSendable.lt(amount)) {
     console.error("Insufficient funds to cover amount plus fee");
   }
   ```

2. **"No Blockchair API key found" warning**: set `USwapConfig.setApiKey("blockchair", ...)`; without a key, requests fall back to rate-limited public endpoints.

## API Reference Summary

### Core Methods

- `getBalance(address)` - Get balances as `AssetValue[]`
- `transfer()` - Send Bitcoin with automatic UTXO selection
- `createTransaction()` - Build an unsigned PSBT with selected inputs
- `broadcastTx(txHex)` - Broadcast a signed raw transaction

### Fee Management

- `getFeeRates()` - Get current fee rates per `FeeOption`
- `estimateTransactionFee()` - Estimate fee for a transaction
- `estimateMaxSendableAmount()` - Balance minus estimated fee
- `calculateTxSize()` - Estimate transaction size in vbytes

### Address and Key Methods

- `getAddress()` - Address of the configured signer
- `validateAddress(address)` - Validate Bitcoin address format
- `createKeysForPath()` / `getAddressFromKeys()` - Derive keys and addresses
- `getPrivateKeyFromMnemonic()` - Export a WIF private key
