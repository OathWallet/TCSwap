This guide covers Cosmos Hub integration with TCSwap, including wallet connections, ATOM transfers, and cross-chain swaps.

## Overview

Cosmos Hub is the first blockchain in the Cosmos ecosystem, designed for interoperability and sovereignty. TCSwap provides Cosmos Hub support through:

- **Cosmos Toolbox**: Native Cosmos SDK operations with ATOM (transfers, balances, signing)
- **Cross-Chain Swaps**: Seamless swaps with other cryptocurrencies via THORChain
- **Multi-Wallet Support**: Compatible with Keplr, Leap, Ledger and other wallets

The same toolbox also serves Kujira (`Chain.Kujira`) and Noble (`Chain.Noble`).

## Cosmos Toolbox

### Wallet Connection

Connect to Cosmos Hub using various wallet types:

```typescript
// @noErrorValidation
import { Chain, FeeOption, WalletOption } from "@tcswap/sdk";

await uSwap.connectKeystore([Chain.Cosmos], "your mnemonic phrase");

await uSwap.connectKeplr([Chain.Cosmos]);

// Leap uses the Keplr connector with a wallet option
await uSwap.connectKeplr([Chain.Cosmos], WalletOption.LEAP);

await uSwap.connectLedger([Chain.Cosmos]);
```

### Address Generation

Cosmos addresses use bech32 format with "cosmos" prefix:

```typescript
// @noErrorValidation
import { getCosmosValidateAddress } from "@tcswap/toolboxes/cosmos";

const cosmosAddress = uSwap.getAddress(Chain.Cosmos);

console.log("Cosmos address:", cosmosAddress);

const validateCosmosAddress = getCosmosValidateAddress(Chain.Cosmos);
console.log("Valid ATOM address:", validateCosmosAddress(cosmosAddress));

// The toolbox exposes the same validator
console.log(cosmosToolbox.validateAddress(cosmosAddress));

// Base64-encoded public key of the signer
const publicKey = await cosmosToolbox.getPubKey();
console.log("Public key:", publicKey);
```

### ATOM Transfers

```typescript
// @noErrorValidation
import { AssetValue } from "@tcswap/sdk";

const txHash = await uSwap.transfer({
  recipient: "cosmos1xv9tklw7d82sezh9haa573wufgy59vmwe6xxe5",
  assetValue: AssetValue.from({
    chain: Chain.Cosmos,
    value: "1",
  }),
  feeOptionKey: FeeOption.Fast,
  memo: "Payment for services",
});

console.log(`Cosmos transaction hash: ${txHash}`);

const toolboxTx = await cosmosToolbox.transfer({
  recipient: "cosmos1xv9tklw7d82sezh9haa573wufgy59vmwe6xxe5",
  assetValue: AssetValue.from({ chain: Chain.Cosmos, value: "0.5" }),
  feeOptionKey: FeeOption.Average,
  memo: "Toolbox transfer",
});

const batchTransfers = async () => {
  const recipients = [
    { address: "cosmos1xv9tklw7d82sezh9haa573wufgy59vmwe6xxe5", amount: "0.1" },
    { address: "cosmos1fl48vsnmsdzcv85q5d2q4z5ajdha8yu34mf0eh", amount: "0.2" },
    {
      address: "cosmos1qypqxpq9qcrsszg2pvxq6rs0zqg3yyc5lzv7xu",
      amount: "0.15",
    },
  ];

  for (const { address, amount } of recipients) {
    const tx = await cosmosToolbox.transfer({
      recipient: address,
      assetValue: AssetValue.from({ chain: Chain.Cosmos, value: amount }),
    });
    console.log(`ATOM sent to ${address}: ${tx}`);
  }
};
```

### Signing Without Broadcasting

`signTransaction` (or `transfer` with `dryRun: true`) returns the signed transaction as a hex string without broadcasting it:

```typescript
// @noErrorValidation

const signedTxHex = await cosmosToolbox.signTransaction({
  recipient: "cosmos1xv9tklw7d82sezh9haa573wufgy59vmwe6xxe5",
  assetValue: AssetValue.from({ chain: Chain.Cosmos, value: "1" }),
  memo: "",
});

console.log("Signed transaction:", signedTxHex);
```

### Account Information

```typescript
// @noErrorValidation

const accountInfo = await cosmosToolbox.getAccount(
  "cosmos1xv9tklw7d82sezh9haa573wufgy59vmwe6xxe5"
);

console.log("Account info:", {
  address: accountInfo?.address,
  accountNumber: accountInfo?.accountNumber,
  sequence: accountInfo?.sequence,
  pubkey: accountInfo?.pubkey,
});

// Returns AssetValue[] (ATOM plus any other non-IBC denoms)
const balances = await cosmosToolbox.getBalance(
  "cosmos1xv9tklw7d82sezh9haa573wufgy59vmwe6xxe5"
);
balances.forEach((balance) => {
  console.log(`${balance.ticker}: ${balance.getValue("string")}`);
});

// Raw denom balances
const denoms = await cosmosToolbox.getBalanceAsDenoms(
  "cosmos1xv9tklw7d82sezh9haa573wufgy59vmwe6xxe5"
);
console.log(denoms);

// Balance of a connected wallet through the client
const walletBalance = await uSwap.getBalance(Chain.Cosmos, true);
```

## Cross-Chain Swaps

Cosmos Hub ATOM is supported in THORChain cross-chain swaps:

```typescript
// @noErrorValidation
import { USwapApi } from "@tcswap/sdk";

const { routes } = await USwapApi.getSwapQuote({
  sellAsset: "GAIA.ATOM",
  sellAmount: "100",
  buyAsset: "BTC.BTC",
  sourceAddress: uSwap.getAddress(Chain.Cosmos),
  destinationAddress: uSwap.getAddress(Chain.Bitcoin),
  slippage: 3,
});

const [bestRoute] = routes;

console.log("ATOM -> BTC quote:", {
  expectedOutput: bestRoute.expectedBuyAmount,
  fees: bestRoute.fees,
  timeEstimate: bestRoute.estimatedTime,
});

const swapTx = await uSwap.swap({
  route: bestRoute,
  feeOptionKey: FeeOption.Fast,
});

const atomToUsdcQuote = await USwapApi.getSwapQuote({
  sellAsset: "GAIA.ATOM",
  sellAmount: "50",
  buyAsset: "ETH.USDC-0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48",
  sourceAddress: uSwap.getAddress(Chain.Cosmos),
  destinationAddress: uSwap.getAddress(Chain.Ethereum),
});

const atomToRuneQuote = await USwapApi.getSwapQuote({
  sellAsset: "GAIA.ATOM",
  sellAmount: "25",
  buyAsset: "THOR.RUNE",
  sourceAddress: uSwap.getAddress(Chain.Cosmos),
  destinationAddress: uSwap.getAddress(Chain.THORChain),
});
```

## Fees

Fee rates are fetched from the TCSwap API with a safe default fallback:

```typescript
// @noErrorValidation
import { estimateTransactionFee, getDefaultChainFee } from "@tcswap/toolboxes/cosmos";

// USwapNumber per FeeOption (average / fast / fastest)
const fees = await cosmosToolbox.getFees();
console.log(`Fast fee: ${fees.fast.getValue("string")} ATOM`);

// Minimum fee as an AssetValue
const minFee = estimateTransactionFee({
  assetValue: AssetValue.from({ chain: Chain.Cosmos, value: "1" }),
});
console.log(`Estimated fee: ${minFee.getValue("string")} ATOM`);

// Default StdFee used when building transactions
console.log(getDefaultChainFee(Chain.Cosmos)); // { amount: [{ amount: "500", denom: "uatom" }], gas: "200000" }
```

## Network Configuration

### Custom RPC Setup

```typescript
// @noErrorValidation
import { USwapConfig } from '@tcswap/sdk';


USwapConfig.setRpcUrl(Chain.Cosmos, [
  "https://cosmos-rpc.publicnode.com",
  "https://cosmos-rpc.publicnode.com:443",
  "https://rpc.cosmos.directory/cosmoshub",
]);
```

The toolbox reads the RPC URL from `USwapConfig`, so configure it before creating the toolbox or connecting a wallet.

## Error Handling

Handle Cosmos-specific errors:

```typescript
// @noErrorValidation
import { USwapError } from "@tcswap/sdk";

try {
  await uSwap.transfer({
    /* ... */
  });
} catch (error) {
  if (error instanceof USwapError) {
    const errorKey = error.message.split(":")[0];

    switch (errorKey) {
      case "core_wallet_connection_not_found":
        console.error("Cosmos wallet is not connected");
        break;
      case "toolbox_cosmos_signer_not_defined":
        console.error("No signer available for this toolbox");
        break;
      case "toolbox_cosmos_account_not_found":
        console.error("Account does not exist on chain yet");
        break;
      case "toolbox_cosmos_invalid_fee":
        console.error("Invalid fee");
        break;
      case "toolbox_cosmos_invalid_params":
        console.error("Invalid transaction parameters");
        break;
      default:
        console.error("Unknown Cosmos error:", error);
    }
  }
}
```

## Best Practices

1. **Validate addresses** before sending:

   ```typescript
   if (!cosmosToolbox.validateAddress(recipient)) {
     throw new Error("Invalid Cosmos address");
   }
   ```

2. **Check balances** before transfers, keeping enough ATOM for fees:

   ```typescript
   const amount = AssetValue.from({ chain: Chain.Cosmos, value: "1" });
   const balances = await cosmosToolbox.getBalance(senderAddress);
   const atomBalance = balances.find((balance) => balance.isGasAsset);
   const fees = await cosmosToolbox.getFees();

   if (!atomBalance || atomBalance.lt(amount.add(fees.fast))) {
     throw new Error("Insufficient ATOM balance");
   }
   ```

## API Reference Summary

### Core Methods

- `getAddress()` - Get the signer address
- `getBalance()` - Get balances as `AssetValue[]`
- `getBalanceAsDenoms()` - Get raw denom balances
- `getAccount()` - Get account information
- `transfer()` - Send ATOM tokens
- `signTransaction()` - Sign a transfer without broadcasting
- `createTransaction()` - Build an unsigned transfer transaction

### Utility Methods

- `getFees()` - Get fee rates per `FeeOption`
- `getPubKey()` - Get the signer public key (base64)
- `validateAddress()` - Validate a Cosmos address
- `verifySignature()` - Verify a signed message
- `getSignerFromPhrase()` / `getSignerFromPrivateKey()` - Create signers
