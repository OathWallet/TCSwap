This guide covers Radix DLT integration with TCSwap, including wallet connections, XRD transfers, and native DeFi operations.

## Overview

Radix DLT is a layer-1 protocol designed specifically for DeFi with atomic composability and linear scalability. TCSwap provides Radix support through:

- **Radix Toolbox**: Balance queries and address validation backed by the Radix Gateway API
- **Radix Wallet**: Connection through the Radix dApp Toolkit, with transaction manifests signed in the Radix Wallet
- **Radix Plugin**: Swaps routed through Caviar (`CAVIAR_V1`)

## Getting Started

### Installation

```bash
# Full SDK (recommended)
bun add @tcswap/sdk

# Individual packages for smaller bundles
bun add @tcswap/toolboxes @tcswap/plugins
```

The standalone toolbox is read-only: it exposes `getBalance`, `validateAddress`, `networkApi` (a Gateway API client) and `getAddress`. Signing happens in the Radix Wallet.

## Radix Toolbox

### Wallet Connection

Radix is connected through the Radix Wallet (via the Radix dApp Toolkit). The dApp definition is read from the `radix` integration config:

```typescript
// @noErrorValidation
import { Chain, USwapConfig } from "@tcswap/sdk";

USwapConfig.setIntegrationConfig("radix", {
  applicationName: "My dApp",
  applicationVersion: "1.0.0",
  dAppDefinitionAddress: "account_rdx...",
  network: { dashboardBase: "https://dashboard.radixdlt.com", networkId: 1, networkName: "mainnet" },
});

await uSwap.connectRadixWallet([Chain.Radix]);
```

### Address Validation

Radix account addresses use the `account_rdx1` prefix:

```typescript
// @noErrorValidation
import { radixValidateAddress } from "@tcswap/toolboxes/radix";

const radixAddress = uSwap.getAddress(Chain.Radix);
console.log("Radix address:", radixAddress);

const isValidAddress = radixValidateAddress(radixAddress);
console.log("Valid Radix address:", isValidAddress);
```

### Balances

`getBalance` returns an `AssetValue` for XRD and every fungible resource held by the account:

```typescript
// @noErrorValidation

const balances = await radixToolbox.getBalance(
  "account_rdx12yy34s8nfpdtjgzcmnqkjlcl5h5lh7x5hljgykgs5p9w4hxm0h6fkr"
);

balances.forEach((asset) => {
  console.log(`${asset.toString()}: ${asset.getValue("string")}`);
});

const walletBalances = await uSwap.getBalance(Chain.Radix, true);
```

### Transactions and Manifests

Transfers are not supported through `uSwap.transfer()` for Radix (the wallet's `transfer` throws `wallet_radix_method_not_supported`). Instead, build a Radix transaction manifest and send it to the Radix Wallet with `signAndBroadcast`:

```typescript
// @noErrorValidation

const radixWallet = uSwap.getWalletByChain(Chain.Radix);
const sender = radixWallet.address;
const recipient = "account_rdx12yy34s8nfpdtjgzcmnqkjlcl5h5lh7x5hljgykgs5p9w4hxm0h6fkr";
const xrd = "resource_rdx1tknxxxxxxxxxradxrdxxxxxxxxx009923554798xxxxxxxxxradxrd";

const manifest = `
CALL_METHOD Address("${sender}") "withdraw" Address("${xrd}") Decimal("100");
TAKE_ALL_FROM_WORKTOP Address("${xrd}") Bucket("xrd");
CALL_METHOD Address("${recipient}") "try_deposit_or_abort" Bucket("xrd") Enum<0u8>();
`;

const txIntentHash = await radixWallet.signAndBroadcast({
  manifest,
  message: "XRD transfer",
});

console.log(`Radix transaction intent hash: ${txIntentHash}`);
```

## Cross-Chain Operations

### Swaps

Radix swaps are routed through Caviar and executed by the Radix plugin, which signs the returned manifest with the connected Radix Wallet:

```typescript
// @noErrorValidation
import { FeeOption, USwapApi } from "@tcswap/sdk";

const { routes } = await USwapApi.getSwapQuote({
  sellAsset: "XRD.XRD",
  sellAmount: "1000",
  buyAsset: "XRD.HUG-resource_rdx1...",
  sourceAddress: uSwap.getAddress(Chain.Radix),
  destinationAddress: uSwap.getAddress(Chain.Radix),
  providers: ["CAVIAR_V1"],
});

if (routes.length > 0) {
  const swapTx = await uSwap.swap({
    route: routes[0],
    feeOptionKey: FeeOption.Fast,
  });

  console.log("Swap transaction:", swapTx);
} else {
  console.log("No route available");
}
```

## Error Handling

```typescript
// @noErrorValidation
import { USwapError } from "@tcswap/sdk";

try {
  await radixWallet.signAndBroadcast({ manifest, message: "" });
} catch (error) {
  if (error instanceof USwapError) {
    switch (error.message.split(":")[0]) {
      case "wallet_radix_not_found":
        console.error("Radix integration config missing");
        break;
      case "wallet_radix_transaction_failed":
        console.error("Transaction was rejected or failed");
        break;
      case "wallet_radix_method_not_supported":
        console.error("Method not supported by the Radix Wallet");
        break;
      default:
        console.error("Unknown error:", error);
    }
  }
}
```

## Best Practices

1. **Validate addresses** before building manifests:

   ```typescript
   import { radixValidateAddress } from "@tcswap/toolboxes/radix";

   if (!radixValidateAddress(recipient)) {
     throw new Error("Invalid Radix address");
   }
   ```

2. **Use atomic manifests**: add `ASSERT_WORKTOP_CONTAINS` instructions so a multi-step manifest fails as a whole if an expected output is missing.

## API Reference Summary

### Radix Toolbox (`RadixToolbox`)

- `getBalance(address)` - Get XRD and fungible resource balances
- `validateAddress(address)` - Validate a Radix account address
- `networkApi` - Radix Gateway API client
- `signAndBroadcast()` - Not supported on the standalone toolbox (throws `toolbox_radix_method_not_supported`)

### Radix Wallet (`uSwap.getWalletByChain(Chain.Radix)`)

- `address` / `getAddress()` - Connected account address
- `getBalance()` - Balances of the connected account
- `signAndBroadcast({ manifest, message })` - Sign a transaction manifest in the Radix Wallet and submit it
- `radixDappToolkit` - Underlying Radix dApp Toolkit instance

### Helpers

- `radixValidateAddress(address)` - Validate a Radix account address
