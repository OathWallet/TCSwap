This guide covers the NEAR Protocol integration in TCSwap, including the NEAR toolbox for direct blockchain operations and the NEAR plugin for enhanced features like NEAR Names service.

## Overview

The NEAR integration provides:

- **NEAR Toolbox**: Core blockchain operations (transfers, balance queries, contract interactions)
- **NEAR Plugin**: NEAR Names service and cross-chain swaps via NEAR
- **NEP-141 Support**: Full support for NEAR's fungible token standard
- **Implicit Accounts**: Support for NEAR's unique implicit account system
- **Contract Factory**: Type-safe contract interactions

## Getting Started

### Installation

```bash
# Using the full SDK (recommended)
npm install @tcswap/sdk

# Or individual packages for smaller bundles
npm install @tcswap/toolboxes @tcswap/plugins
```

## NEAR Toolbox

### Account Management

NEAR supports two types of accounts:

- **Named accounts**: Human-readable names like `alice.near`
- **Implicit accounts**: 64-character hex strings derived from public keys

```typescript
// @noErrorValidation

const toolbox = await getNearToolbox({
  phrase: "your mnemonic phrase",
});

const accountId = await toolbox.getAddress();
console.log(accountId);

const publicKey = await toolbox.getPublicKey();
console.log(publicKey);
```

### Native NEAR Transfers

```typescript
// @noErrorValidation
import { AssetValue } from "@tcswap/sdk";

const txHash = await toolbox.transfer({
  recipient: "receiver.near",
  assetValue: AssetValue.from({
    chain: Chain.Near,
    value: "1.5",
  }),
  memo: "Payment for services",
});

console.log(`Transaction hash: ${txHash}`);
```

### NEP-141 Token Transfers

NEP-141 is NEAR's fungible token standard, similar to ERC-20 on Ethereum. When the asset has a contract address, `transfer` checks the recipient's storage registration and pays the storage deposit automatically if needed.

```typescript
// @noErrorValidation

const usdcTransfer = await toolbox.transfer({
  recipient: "receiver.near",
  assetValue: AssetValue.from({
    chain: Chain.Near,
    symbol: "USDC",
    address: "usdc.near",
    value: "100",
  }),
});
```

### Smart Contract Interactions

The NEAR toolbox provides multiple ways to interact with smart contracts:

#### Direct Function Calls

```typescript
// @noErrorValidation

const txHash = await toolbox.callFunction({
  contractId: "my-contract.near",
  methodName: "set_value",
  args: { key: "name", value: "Alice" },
  deposit: "1000000000000000000000000",
});
```

#### Typed Contract Interface

For better type safety and developer experience:

```typescript
// @noErrorValidation

const contractInterface = {
  contractId: "my-dapp.near",
  viewMethods: ["get_balance", "get_user_info"],
  changeMethods: ["deposit", "withdraw", "transfer"],
};

const contract = await toolbox.createContract(contractInterface);

const balance = await contract.get_balance({ account: "alice.near" });
```

### Sub-Account Management

NEAR allows creating sub-accounts under your main account:

```typescript
// @noErrorValidation

const subAccountId = `sub.${accountId}`;
const subAccountPubKey = "ed25519:...";

const txHash = await toolbox.createSubAccount(
  subAccountId,
  subAccountPubKey,
  "5"
);

console.log(`Created sub-account: ${subAccountId}`);
```

### Gas Estimation

NEAR uses a fixed gas price determined by the network, so there's no concept of fee priority:

```typescript
// @noErrorValidation

const transferFee = await toolbox.estimateTransactionFee({
  recipient: "receiver.near",
  assetValue: AssetValue.from({ chain: Chain.Near, value: "1" }),
});

const callFee = await toolbox.estimateGas({
  contractId: "contract.near",
  methodName: "complex_operation",
  args: {
    /* ... */
  },
});

console.log(`Estimated cost: ${callFee.toSignificant(6)} NEAR`);
```

## NEAR Plugin

The NEAR plugin extends TCSwap with NEAR-specific features:

### NEAR Names Service

NEAR Names is a decentralized naming service similar to ENS on Ethereum:

```typescript
// @noErrorValidation
import { createUSwap } from "@tcswap/sdk";

const uSwap = createUSwap();

const isAvailable = await uSwap.near.nearNames.isAvailable("myname");

if (isAvailable) {
  const txHash = await uSwap.near.nearNames.register({
    name: "myname",
    publicKey: "ed25519:...",
  });
  console.log(`Registered myname.near: ${txHash}`);
}

const accountId = await uSwap.near.nearNames.resolve("alice");
console.log(`alice.near exists: ${accountId !== null}`);

const info = await uSwap.near.nearNames.getInfo("alice");
console.log(info);

const names = await uSwap.near.nearNames.lookupNames(
  "8fac9c5b1f4e8b4c9a7d2e6f1a3b5c7d9e2f4a6b8c1d3e5f7a9b1c3d5e7f9a1b"
);
console.log(`Names owned: ${names}`);

const transferTx = await uSwap.near.nearNames.transfer("myname", "new-owner.near");
```

### Cross-Chain Swaps via NEAR

The NEAR plugin supports cross-chain swaps using NEAR as an intermediary:

```typescript
// @noErrorValidation

import { USwapApi } from "@tcswap/sdk";

const { routes } = await USwapApi.getSwapQuote({
  sellAsset: "ETH.ETH",
  sellAmount: "0.1",
  buyAsset: "NEAR.NEAR",
  sourceAddress: "0x...",
  destinationAddress: "receiver.near",
  providers: ["NEAR"],
});

const swapTx = await uSwap.swap({ route: routes[0] });
```

## Fee Rate Configuration

NEAR Protocol uses a fixed gas price determined by the network validators. Unlike some other chains, NEAR doesn't support fee priority or multipliers - all transactions pay the same gas price:

```typescript
// @noErrorValidation

const fee = await toolbox.estimateTransactionFee({
  recipient: "receiver.near",
  assetValue: AssetValue.from({ chain: Chain.Near, value: "1" }),
});
```

## Error Handling

NEAR operations can throw specific errors that should be handled:

```typescript
// @noErrorValidation
import { USwapError } from "@tcswap/sdk";

try {
  await toolbox.transfer({
    /* ... */
  });
} catch (error) {
  if (error instanceof USwapError) {
    switch (error.message.split(":")[0]) {
      case "toolbox_near_no_signer":
        console.error("No signer available");
        break;
      case "toolbox_near_invalid_address":
        console.error("Invalid NEAR address");
        break;
      case "toolbox_near_invalid_amount":
        console.error("Invalid transfer amount");
        break;
      case "toolbox_near_transfer_failed":
        console.error("Transfer failed:", error.cause);
        break;
      case "plugin_near_invalid_name":
        console.error("Invalid NEAR name format");
        break;
      default:
        console.error("Unknown error:", error);
    }
  }
}
```

## Advanced Features

### Custom Signer Implementation

You can provide your own signer (any `NearSigner` implementation), for example one built from a private key:

```typescript
// @noErrorValidation
import { getNearSignerFromPrivateKey, getNearToolbox } from "@tcswap/toolboxes/near";

const customSigner = await getNearSignerFromPrivateKey("ed25519:...");

const toolbox = await getNearToolbox({
  signer: customSigner,
  accountId: "custom.near",
});
```

### Working with Test Networks

To use NEAR testnet:

```typescript
// @noErrorValidation
import { USwapConfig } from '@tcswap/sdk';


USwapConfig.setEnv('isStagenet', true);
USwapConfig.setRpcUrl(Chain.Near, ['https://rpc.mainnet.near.org']);


const toolbox = await getNearToolbox({ phrase: "..." });
```

### Gas Helper Functions

The NEAR toolbox package exports utility functions for gas calculations:

```typescript
// @noErrorValidation
import { tgasToGas, gasToTGas } from "@tcswap/toolboxes/near";

const gasUnits = tgasToGas("30");

const tgas = gasToTGas("30000000000000");
```

## Best Practices

1. **Always validate addresses** before sending transactions:

   ```typescript
   import { getValidateNearAddress } from "@tcswap/toolboxes/near";

   const validateNearAddress = await getValidateNearAddress();

   if (!validateNearAddress(recipient)) {
     throw new Error("Invalid NEAR address");
   }
   ```

2. **Use appropriate gas amounts** for contract calls:

   ```typescript
   const gas = tgasToGas("100");
   ```

3. **Handle implicit accounts** carefully:

   ```typescript
   const implicitAccount =
     "8fac9c5b1f4e8b4c9a7d2e6f1a3b5c7d9e2f4a6b8c1d3e5f7a9b1c3d5e7f9a1b";

   try {
     const balance = await toolbox.getBalance(implicitAccount);
   } catch {}
   ```
