Keplr is the leading browser extension wallet for the Cosmos ecosystem, providing secure access to Cosmos-based networks. TCSwap supports Keplr through `keplrWallet`, which exposes the `connectKeplr` method for Cosmos Hub, THORChain, Kujira and Noble, as well as EVM chains and Bitcoin through Keplr's injected providers.

## Supported Chains

`connectKeplr` accepts the following chains (`KEPLR_SUPPORTED_CHAINS`):

- **Cosmos ecosystem**: Cosmos Hub (`Chain.Cosmos`), THORChain (`Chain.THORChain`), Kujira (`Chain.Kujira`), Noble (`Chain.Noble`)
- **EVM chains**: every chain in `EVMChains` (Ethereum, Arbitrum, Avalanche, Base, BNB Smart Chain, Optimism, Polygon, etc.) via Keplr's injected Ethereum provider (`window.keplr.ethereum`)
- **Bitcoin** (`Chain.Bitcoin`) via Keplr's Bitcoin provider (`window.keplr.bitcoin`)

Chains not in this list are ignored with a console warning. If none of the requested chains are supported, `connectKeplr` throws `wallet_chain_not_supported`. If the installed Keplr version does not expose the Ethereum or Bitcoin provider, connecting those chains throws `wallet_keplr_chain_not_supported`.

The same `connectKeplr` method also connects **Leap** wallet when you pass `WalletOption.LEAP` as the second argument.

## Installation and Setup

### 1. Install Keplr Extension

Install Keplr from the official sources:

- **Chrome/Chromium**: [Download](https://www.keplr.app/get)
- **Firefox**: [Download](https://www.keplr.app/get)
- **Brave**: Available through Chrome Web Store

### 2. Set Up Keplr Wallet

1. Create a new wallet or import existing one using your seed phrase
2. Set up a secure password
3. The wallet will automatically include major Cosmos chains
4. Additional chains can be added as needed

### 3. Browser Requirements

Keplr works in:

- **Chrome/Chromium**: Full support
- **Firefox**: Full support
- **Safari**: Limited support
- **Brave**: Full support
- **Edge**: Full support

### Connecting Keplr

#### Basic Cosmos Connection

```ts twoslash
import { USwap, keplrWallet, Chain, WalletOption } from "@tcswap/sdk";

const uSwap = USwap({
  wallets: { ...keplrWallet },
});

async function connectKeplr() {
  try {
    await uSwap.connectKeplr([Chain.Cosmos]);

    const address = uSwap.getAddress(Chain.Cosmos);
    const balance = await uSwap.getBalance(Chain.Cosmos, true);

    console.log("Cosmos address:", address);
    console.log("ATOM balance:", balance);

    return { success: true, address, balance };
  } catch (error) {
    console.error("Failed to connect Keplr:", error);
    return { success: false, error };
  }
}
```

#### Multi-Chain Connection

```ts twoslash
import { USwap, keplrWallet, Chain, WalletOption } from "@tcswap/sdk";

const uSwap = USwap({
  wallets: { ...keplrWallet },
});

async function connectMultipleCosmosChains() {
  const cosmosChains = [
    Chain.Cosmos,
    Chain.THORChain,
    Chain.Kujira,
    Chain.Noble,
  ];

  try {
    await uSwap.connectKeplr(cosmosChains);

    const addresses = {};
    for (const chain of cosmosChains) {
      addresses[chain] = uSwap.getAddress(chain);
      console.log(`${chain} address:`, addresses[chain]);
    }

    const balances = await Promise.all(
      cosmosChains.map(async (chain) => {
        const balance = await uSwap.getBalance(chain, true);
        return { chain, balance };
      })
    );

    return { success: true, addresses, balances };
  } catch (error) {
    console.error("Multi-chain connection failed:", error);
    return { success: false, error };
  }
}
```

## Transaction Examples

import { USwap, keplrWallet, Chain, AssetValue } from "@tcswap/sdk";

const uSwap = USwap({
  wallets: { ...keplrWallet },

await uSwap.connectKeplr([Chain.Cosmos]);

async function sendAtom() {
  const recipient = "cosmos1xy2kgdygjrsqtzq2n0yrf2493p83kkfjhx0wlh";
  const amount = AssetValue.from({ asset: "GAIA.ATOM", value: 1 });

  try {
    console.log("Sending ATOM transaction...");
    console.log("Amount:", amount.toSignificant(6), "ATOM");
    console.log("To:", recipient);

  } catch (error) {
    console.error("❌ ATOM transaction failed:", error);
    throw error;
  }
}

## Common Troubleshooting

### Connection Issues

```ts twoslash

import { USwap, keplrWallet, Chain } from "@tcswap/sdk";

const uSwap = USwap({
  wallets: { ...keplrWallet },
});

async function diagnosticConnection() {
  try {

    if (typeof window.keplr === 'undefined') {
      console.error("❌ Keplr extension not found");
      console.log("🔧 Install Keplr extension from https://www.keplr.app/get");
      return { success: false, error: "Keplr not installed" };
    }

    console.log("🔍 Keplr detected, attempting connection...");

    await uSwap.connectKeplr([Chain.Cosmos]);

    const address = uSwap.getAddress(Chain.Cosmos);
    console.log("✅ Successfully connected:", address);

    return { success: true, address };
  } catch (error) {
    console.error("❌ Connection failed:", error);

    if (error.message.includes("rejected")) {
      console.log("🔧 User rejected connection request");
      console.log("Please approve the connection in Keplr");
    }

    if (error.message.includes("locked")) {
      console.log("🔧 Keplr wallet is locked");
      console.log("Please unlock your Keplr wallet");
    }

    if (error.message.includes("chain_not_supported")) {
      console.log("🔧 Chain not supported by connectKeplr or by the installed Keplr version");
      console.log("Supported: Cosmos, THORChain, Kujira, Noble, EVM chains and Bitcoin");
    }

    return { success: false, error };
  }
}


async function checkKeplrStatus() {
  if (!window.keplr) {
    return { installed: false };
  }

  try {

    const key = await window.keplr.getKey("cosmoshub-4");

    return {
      installed: true,
      connected: true,
      address: key.bech32Address,
      name: key.name,
    };
  } catch (error) {
    return {
      installed: true,
      connected: false,
      error: error.message,
    };
  }
}
```

### Transaction Failures

```ts twoslash
async function handleTransactionErrors() {
  try {
    const amount = AssetValue.from({ asset: "GAIA.ATOM", value: 1 });
    const txHash = await uSwap.transfer({
      assetValue: amount,
      recipient: "cosmos1xy2kgdygjrsqtzq2n0yrf2493p83kkfjhx0wlh",
      memo: "Test transaction",
    });
    return txHash;
  } catch (error) {
    if (error.message.includes("insufficient funds")) {
      console.error("❌ Insufficient ATOM balance");

      const balance = await uSwap.getBalance(Chain.Cosmos, true);
      console.log("Current balance:", balance);
      console.log("🔧 Add more ATOM to your wallet");
    }

    if (error.message.includes("gas")) {
      console.error("❌ Gas estimation failed");
      console.log("🔧 Check network status or try increasing gas in Keplr");
    }

    if (error.message.includes("sequence")) {
      console.error("❌ Sequence mismatch (nonce issue)");
      console.log("🔧 Wait a moment and try again");
    }

    if (error.message.includes("rejected")) {
      console.error("❌ Transaction rejected in Keplr");
      console.log("🔧 Please approve the transaction in Keplr popup");
    }

    if (error.message.includes("timeout")) {
      console.error("❌ Transaction timed out");
      console.log("🔧 Check network connectivity and try again");
    }

    throw error;
  }
}
```

## React Integration

```tsx twoslash

import React, { useState, useEffect } from 'react';
import { USwap, keplrWallet, Chain, WalletOption, AssetValue } from "@tcswap/sdk";

interface KeplrWalletProps {
  onConnect: (addresses: Record<Chain, string>) => void;
  onError: (error: Error) => void;
}

export function KeplrWallet({ onConnect, onError }: KeplrWalletProps) {
  const [isConnecting, setIsConnecting] = useState(false);
  const [isConnected, setIsConnected] = useState(false);
  const [addresses, setAddresses] = useState<Record<Chain, string>>({});
  const [selectedChains, setSelectedChains] = useState<Chain[]>([Chain.Cosmos]);

  const uSwap = USwap({ wallets: { ...keplrWallet } });


  const isKeplrInstalled = typeof window !== 'undefined' &&
    typeof window.keplr !== 'undefined';

  useEffect(() => {
    if (!isKeplrInstalled) return;


    const handleAccountChange = () => {
      if (isConnected) {

        connectKeplr();
      }
    };

    window.addEventListener('keplr_keystorechange', handleAccountChange);

    return () => {
      window.removeEventListener('keplr_keystorechange', handleAccountChange);
    };
  }, [isConnected, isKeplrInstalled]);

  const connectKeplr = async () => {
    if (!isKeplrInstalled) {
      onError(new Error("Keplr not installed"));
      return;
    }

    setIsConnecting(true);

    try {
      await uSwap.connectKeplr(selectedChains);

      const connectedAddresses: Record<Chain, string> = {};
      for (const chain of selectedChains) {
        connectedAddresses[chain] = uSwap.getAddress(chain);
      }

      setAddresses(connectedAddresses);
      setIsConnected(true);
      onConnect(connectedAddresses);
    } catch (error) {
      onError(error as Error);
    } finally {
      setIsConnecting(false);
    }
  };

  const disconnect = () => {
    uSwap.disconnectAll();
    setIsConnected(false);
    setAddresses({});
  };

  const toggleChain = (chain: Chain) => {
    if (isConnected) return;

    setSelectedChains(prev =>
      prev.includes(chain)
        ? prev.filter(c => c !== chain)
        : [...prev, chain]
    );
  };

  if (!isKeplrInstalled) {
    return (
      <div>
        <h3>Keplr Wallet</h3>
        <p>Keplr extension not detected</p>
        <a
          href="https://www.keplr.app/get"
          target="_blank"
          rel="noopener noreferrer"
        >
          Install Keplr
        </a>
      </div>
    );
  }

  return (
    <div>
      <h3>Keplr Wallet</h3>

      {!isConnected ? (
        <div>
          <h4>Select Chains:</h4>
          {[Chain.Cosmos, Chain.THORChain, Chain.Kujira, Chain.Noble].map(chain => (
            <label key={chain}>
              <input
                type="checkbox"
                checked={selectedChains.includes(chain)}
                onChange={() => toggleChain(chain)}
                disabled={isConnecting}
              />
              {chain}
            </label>
          ))}

          <button
            onClick={connectKeplr}
            disabled={isConnecting || selectedChains.length === 0}
          >
            {isConnecting ? "Connecting..." : "Connect Keplr"}
          </button>
        </div>
      ) : (
        <div>
          <h4>Connected Addresses:</h4>
          {Object.entries(addresses).map(([chain, address]) => (
            <div key={chain}>
              <strong>{chain}:</strong> {address}
            </div>
          ))}
          <button onClick={disconnect}>Disconnect</button>
        </div>
      )}
    </div>
  );
}
```
