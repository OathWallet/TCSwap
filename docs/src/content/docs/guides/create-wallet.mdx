This guide explains how to create a custom wallet adapter for TCSwap using the `createWallet` function.

## Wallet Adapter Structure

A TCSwap wallet adapter consists of:

1. A wallet factory created with `createWallet` (`name`, `walletType`, `supportedChains`, `connect`)
2. A connect function that resolves each requested chain's address and toolbox
3. Calls to `addChain` that register a chain wallet (`chain`, `address`, `walletType` plus toolbox methods such as `transfer` and `getBalance`) on the TCSwap client

## Basic Wallet Adapter Example

Here's a simple example of creating a custom wallet adapter for an injected EIP-1193 provider:

```ts twoslash
import {
  Chain,
  createWallet,
  filterSupportedChains,
  getEvmToolbox,
  USwapError,
  type EVMChain,
} from "@tcswap/sdk";
import { BrowserProvider } from "ethers";

export const myCustomWallet = createWallet({
  name: "connectMyCustomWallet",
  walletType: "custom",
  supportedChains: [
    Chain.Ethereum,
    Chain.BinanceSmartChain,
    Chain.Avalanche,
    Chain.Polygon,
  ],
  connect: ({ addChain, supportedChains, walletType }) =>
    async function connectMyCustomWallet(chains: Chain[]) {
      // Throws `wallet_chain_not_supported` if none of the chains are supported
      const filteredChains = filterSupportedChains({ chains, supportedChains });

      if (!window.ethereum) {
        throw new USwapError("core_wallet_connection_not_found");
      }

      const provider = new BrowserProvider(window.ethereum, "any");

      for (const chain of filteredChains) {
        await provider.send("eth_requestAccounts", []);
        const signer = await provider.getSigner();
        const address = await signer.getAddress();

        const toolbox = await getEvmToolbox(chain as EVMChain, { provider, signer });

        addChain({
          ...toolbox,
          getBalance: () => toolbox.getBalance(address),
          chain,
          walletType,
          address,
        });
      }

      return true;
    },
});
```

## Wallet with Hardware Connection

Here's an example of creating a wallet adapter for a hardware wallet:

```ts twoslash
import {
  Chain,
  FeeOption,
  createWallet,
  filterSupportedChains,
  getEvmToolbox,
  getUtxoToolbox,
  type EVMChain,
  type GenericTransferParams,
} from "@tcswap/sdk";
import type { Signer } from "ethers";

// Replace these stubs with your device SDK
declare function detectDevice(): Promise<string | undefined>;
declare function getAddressFromDevice(chain: Chain, deviceId: string): Promise<string>;
declare function signPsbtWithDevice(deviceId: string, psbt: unknown, inputs: unknown): Promise<string>;
declare function createHardwareSigner(deviceId: string, chain: EVMChain): Signer;

export const customHardwareWallet = createWallet({
  name: "connectCustomHardware",
  walletType: "customHardwareName",
  supportedChains: [Chain.Bitcoin, Chain.Ethereum, Chain.BinanceSmartChain],
  connect: ({ addChain, supportedChains, walletType }) =>
    async function connectCustomHardware(chains: Chain[], options?: { deviceId?: string }) {
      const filteredChains = filterSupportedChains({ chains, supportedChains });
      const deviceId = options?.deviceId || (await detectDevice());

      if (!deviceId) {
        return false;
      }

      for (const chain of filteredChains) {
        const address = await getAddressFromDevice(chain, deviceId);

        if (chain === Chain.Bitcoin) {
          const btcToolbox = await getUtxoToolbox(Chain.Bitcoin);

          addChain({
            ...btcToolbox,
            chain,
            walletType,
            address,
            getBalance: () => btcToolbox.getBalance(address),
            transfer: async (params: GenericTransferParams) => {
              const feeRate =
                params.feeRate || (await btcToolbox.getFeeRates())[FeeOption.Average];

              const { psbt, inputs } = await btcToolbox.createTransaction({
                ...params,
                feeRate,
                fetchTxHex: true,
                sender: address,
              });

              const signedTxHex = await signPsbtWithDevice(deviceId, psbt, inputs);

              return btcToolbox.broadcastTx(signedTxHex);
            },
          });
        } else {
          const evmChain = chain as EVMChain;
          const evmToolbox = await getEvmToolbox(evmChain, {
            signer: createHardwareSigner(deviceId, evmChain),
          });

          addChain({
            ...evmToolbox,
            getBalance: () => evmToolbox.getBalance(address),
            chain,
            walletType,
            address,
          });
        }
      }

      return true;
    },
});
```

## Using Your Custom Wallet with TCSwap

Spread the wallet into `wallets`; the connect method is exposed on the client under the wallet's `name`:

```ts twoslash
import { USwap, Chain } from "@tcswap/sdk";
import { myCustomWallet } from "./my-custom-wallet";

const uSwap = USwap({
  wallets: { ...myCustomWallet },
});

async function connectWithCustomWallet() {
  await uSwap.connectMyCustomWallet([Chain.Ethereum, Chain.BinanceSmartChain]);

  const ethWallet = uSwap.getWalletByChain(Chain.Ethereum);
  const ethAddress = uSwap.getAddress(Chain.Ethereum);
}
```

To keep the default wallets as well, use `createUSwap({ wallets: { ...myCustomWallet } })`, which merges yours with the defaults.

## Testing Your Wallet Adapter

Test your wallet adapter thoroughly before using it in production:

```ts twoslash
import { describe, mock, it, expect, beforeEach } from "bun:test";
import { Chain, AssetValue, USwap } from "@tcswap/sdk";
import { myCustomWallet } from "./my-custom-wallet";

const ADDRESS = "0x742d35Cc6634C0532925a3b844Bc454e4438f44e";
const createClient = () => USwap({ wallets: { ...myCustomWallet } });

describe("MyCustomWallet", () => {
  let uSwap: ReturnType<typeof createClient>;

  beforeEach(() => {
    // Minimal EIP-1193 mock; extend it with the RPC methods your test needs
    globalThis.window = {
      ethereum: {
        request: mock(async ({ method }: { method: string }) => {
          if (method === "eth_requestAccounts" || method === "eth_accounts") return [ADDRESS];
          if (method === "eth_chainId") return "0x1";
          return null;
        }),
      },
    } as any;

    uSwap = createClient();
  });

  it("should connect to Ethereum", async () => {
    await uSwap.connectMyCustomWallet([Chain.Ethereum]);

    const wallets = uSwap.getAllWallets();
    expect(wallets[Chain.Ethereum]).toBeDefined();
    expect(wallets[Chain.Ethereum].address).toBe(ADDRESS);
  });

  it("should transfer ETH", async () => {
    await uSwap.connectMyCustomWallet([Chain.Ethereum]);

    const mockTransfer = mock(async () => "0xtxhash");
    uSwap.getWalletByChain(Chain.Ethereum).transfer = mockTransfer;

    const result = await uSwap.transfer({
      assetValue: AssetValue.from({ chain: Chain.Ethereum, value: "0.1" }),
      recipient: "0xabc123...",
    });

    expect(mockTransfer).toHaveBeenCalled();
    expect(result).toBe("0xtxhash");
  });
});
```

## Best Practices

When creating a custom wallet adapter, follow these best practices:

1. **Error Handling**: Provide clear error messages when connection or operations fail
2. **Chain Filtering**: Properly filter and validate supported chains
3. **Feature Detection**: Check if features like signing or specific networks are supported
4. **Security**: Be careful with private keys and sensitive operations
5. **Testing**: Test thoroughly with both happy and error paths
6. **Documentation**: Document any special requirements or features of your wallet

By following this guide, you can create a custom wallet adapter that integrates seamlessly with the TCSwap ecosystem.
