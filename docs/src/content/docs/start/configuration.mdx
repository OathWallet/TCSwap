TCSwap uses a centralized configuration system called `USwapConfig` that manages all settings across [toolboxes](/start/toolbox-usage), [plugins](/guides/create-plugin), and integrations. This guide covers how to configure TCSwap for your application.

## Configuration Overview

TCSwap's configuration is managed through the `USwapConfig` store, which handles:

- RPC URLs for blockchain connections
- API keys for external services
- Environment settings
- Integration configurations
- Custom API endpoint implementations

## Basic Configuration

When creating a TCSwap instance, you can provide configuration options:

```typescript
// @noErrorValidation
import { createUSwap } from '@tcswap/sdk';

const uSwap = createUSwap({
  config: {

    apiKeys: {
      walletConnectProjectId: 'your-project-id',
      blockchair: 'your-blockchair-key',
      uSwap: 'your-uswap-key'
    },

    rpcUrls: {
      ETH: ['https://eth-mainnet.g.alchemy.com/v2/your-key'],
      AVAX: ['https://api.avax.network/ext/bc/C/rpc']
    }
  }
});
```

## API Keys

### TCSwap API Key

The TCSwap API key unlocks enhanced features:

- Higher rate limits
- Advanced swap routes
- Priority support

Get your key at [affiliate.thorchain.org](https://affiliate.thorchain.org)

```typescript
// @noErrorValidation
apiKeys: {
  uSwap: "your-uswap-api-key";
}
```

### WalletConnect Project ID

Required for WalletConnect v2 integration:

```typescript
// @noErrorValidation
apiKeys: {
  walletConnectProjectId: "your-project-id";
}
```

Get your project ID at [cloud.reown.com](https://cloud.reown.com)

### Blockchair API Key

Enables full functionality for UTXO chains (Bitcoin, Litecoin, Dogecoin, etc.):

```typescript
// @noErrorValidation
apiKeys: {
  blockchair: "your-blockchair-key";
}
```

Without this key, UTXO chain functionality is limited. Get your key at [blockchair.com/api](https://blockchair.com/api)

## RPC URLs

TCSwap provides default RPC URLs for all supported chains, but you can override them. Each chain takes an array of URLs:

```typescript
// @noErrorValidation
import { createUSwap, Chain } from '@tcswap/sdk';

const uSwap = createUSwap({
  config: {
    rpcUrls: {
      [Chain.Ethereum]: ['https://eth-mainnet.g.alchemy.com/v2/your-key'],
      [Chain.Avalanche]: ['https://api.avax.network/ext/bc/C/rpc'],
      [Chain.BinanceSmartChain]: ['https://bsc-dataseed.binance.org/'],
      [Chain.Polygon]: ['https://polygon-rpc.com']
    }
  }
});
```

## Runtime Configuration

You can update configuration after initialization using `USwapConfig`:

```typescript
// @noErrorValidation
import { USwapConfig, Chain } from '@tcswap/sdk';


USwapConfig.setRpcUrl(Chain.Ethereum, ['https://new-rpc-url.com']);


USwapConfig.setApiKey('blockchair', 'new-api-key');


USwapConfig.setEnv('isStagenet', true);


const currentRpcUrl = USwapConfig.get('rpcUrls')[Chain.Ethereum];
const apiKeys = USwapConfig.get('apiKeys');
```

## Environment Settings

Control TCSwap's behavior with environment flags:

```typescript
// @noErrorValidation
const uSwap = createUSwap({
  config: {
    envs: {
      isDev: true,

      isStagenet: true,
    },
  },
});
```

Configure Chainflip integration:

```typescript
// @noErrorValidation
USwapConfig.setIntegrationConfig('chainflip', {
  useSDKBroker: true,

```

## Custom API Implementations

Override the TCSwap API endpoints (`getBalance`, `getQuote`, `getRouteWithTx`) with your own implementations:

```typescript
// @noErrorValidation
import { USwapConfig } from "@tcswap/sdk";

USwapConfig.set({
  endpoints: {
    getBalance: async ({ chain, address }) => {
      // return BalanceResponse
    },
    getQuote: async (quoteRequest) => {
      // return QuoteResponse
    },
  },
});

USwapConfig.setEndpoint("getRouteWithTx", async ({ routeId }) => {
  // return QuoteResponseRoute
});
```

## Complete Example

Here's a production-ready configuration example:

```typescript
// @noErrorValidation
import { createUSwap, USwapConfig, Chain } from '@tcswap/sdk';


const config = {

  apiKeys: {
    walletConnectProjectId: process.env.WALLETCONNECT_PROJECT_ID!,
    blockchair: process.env.BLOCKCHAIR_API_KEY,
    uSwap: process.env.USWAP_API_KEY
  },


  envs: {
    isDev: process.env.NODE_ENV === 'development',
    isStagenet: process.env.USE_TESTNET === 'true'
  },


  rpcUrls: {
    [Chain.Ethereum]: [process.env.ETH_RPC_URL || 'https://eth.llamarpc.com'],
    [Chain.Avalanche]: [process.env.AVAX_RPC_URL || 'https://api.avax.network/ext/bc/C/rpc'],
    [Chain.BinanceSmartChain]: [process.env.BSC_RPC_URL || 'https://bsc-dataseed.binance.org'],
  }
};


const uSwap = createUSwap({ config });


if (userPrefersFastNode) {
  USwapConfig.setRpcUrl(Chain.Ethereum, ['https://premium-eth-rpc.com']);
}


if (userHasRadixWallet) {
  USwapConfig.setIntegrationConfig('radix', {
    dAppDefinitionAddress: process.env.RADIX_DAPP_ADDRESS!,
    applicationName: 'My USwap App',
    applicationVersion: '1.0.0',
    network: {
      networkId: config.envs.isStagenet ? 2 : 1,
      networkName: config.envs.isStagenet ? 'testnet' : 'mainnet',
      dashboardBase: 'https://dashboard.radixdlt.com'
    }
  });
}
```

## Troubleshooting

### RPC Connection Issues

If you're experiencing connection issues:

```typescript
// @noErrorValidation

const currentRpc = USwapConfig.get('rpcUrls')[Chain.Ethereum];
console.log('Current Ethereum RPC:', currentRpc);


USwapConfig.setRpcUrl(Chain.Ethereum, ['https://cloudflare-eth.com']);
```

### API Key Validation

Verify your API keys are working:

```typescript
// @noErrorValidation
import { USwapApi } from "@tcswap/sdk";

try {
  const price = await USwapApi.getPrice({
    tokens: [{ identifier: "ETH.ETH" }],
    metadata: false,
  });
  console.log("USwap API key is valid");
} catch (error) {
  console.error("USwap API key issue:", error);
}
```
